# 开源字体

Noto Serif SC、Noto Sans SC、马善政三个字库来自Google Fonts官方ofl目录；霞鹜文楷 Medium（LXGWWenKai-Medium.ttf）来自作者官方GitHub发布页v1.522，保留原始SIL OFL1.1、版权声明及未修改字库。正式来源和文件SHA256见来源与许可证.json。允许使用字体制作图片；字体再分发遵循各原OFL文件。

正文宋体500/600、白大字700、浅篇黑标题900；黑体用于姓名/图注；马善政用于彩色大字；文楷是正文可选字体（手排.py body(font='文楷')）。渲染的仿斜体/加粗/挤出不修改字体文件。licensed目录仅说明，无商业字库和私人凭证。
