# 仅存合法授权字库

此目录空置，只有说明。不随Skill提供华康或其他商业字库，也不存私人授权凭证。

用户取得授权后，把字体放自己的工作目录 `fonts/licensed/`，授权凭证放 `research/授权凭证/`（仅本地私有，不公开打包）。授权登记必填：

- 授权方与正式合同/订单编号。
- 字体全称、版本、字库文件SHA256、TTC index。
- 授权范围：具体平台、商业用途、传播方式、地域与是否允许再分发。
- 起止期限与续约限制。
- 对应账号主体、名称及授权使用人。

未提供正式文件与凭证时，使用内置开源字体。严禁第三方“免费下载”字库和来源不明系统副本。

页面配置：`fonts.licensed_headline`的path相对素材根目录；index默认0；变量字库才设weight，静态W8省略weight或设null。覆盖headline、cover-title、heading，正文不变。

接入命令和回退行为见Skill与使用说明；凭证保存在工作目录，不能复制回这个可分发Skill。
