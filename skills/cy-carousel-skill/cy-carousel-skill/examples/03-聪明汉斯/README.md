# 例 03｜聪明的汉斯 → AI 的「聪明汉斯效应」（AI 科技线）

1904 年柏林一匹会「算数」的马，其实在看提问人头部不到 1 毫米的抬头；一百多年后，AI 模型也会靠不该用的线索拿高分。暗底、电子青强调色，ELIZA 式手排。

![全套预览](全套预览.jpg)

- 体裁：反差钩子 → 两次盲测（98%→8%、35 次只对 2 次）→ 破案 → 定义页大字公式 → 两个 AI 案例 → 金句收尾＋三条思考。
- 素材：Krall《Denkende Tiere》1912 里的老照片（Wikimedia Commons，公有领域）、Pfungst 1911 英译本书页（Internet Archive）、斯图姆夫像（Wellcome Collection，CC BY 4.0）、Lapuschkin 2019 与 Zech 2018 论文图和原句（CC BY 4.0）。
- 做法：`制作.py` 用 `scripts/手排.py` 逐页手写位置；书页纸条用 `scan_strip()`＋Vision 词框，论文纸条用 `strip()` 矢量渲染；整页压暗照片用 `backdrop()`。
- 查证：事实表 91 条，三组审稿＋两轮成稿复核。
- 原图和事实表未随包提供；`制作.py` 里的素材路径要换成你自己下载的文件。出处见成品置顶评论。
