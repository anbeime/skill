# 例 02｜OpenAI Dots：ChatGPT 有了自己的电脑（浅色纸底，推荐对照）

新品速递：Dots 不是新模型，而是给模型配了一台云电脑。浅色纸底，同样的毛笔双色标题、原文纸条红圈和电子青大字。

![全套预览](全套预览.jpg)

- 体裁：反差钩子（关掉聊天窗口它还在干活）→ 它是什么（GPT-6 Astra＋云电脑，4000+ 应用）→ 同一句话普通 ChatGPT 和 Dots 的对比 → 能分活、能在 Slack/Teams 里喊 → 权限边界（碰不到你的电脑、发票先问你）→ 谁能用 → 产品经理视角三个问题 → 金句收尾。
- 素材以官方截图、发布视频关键帧和媒体报道原句为主，关键处红圈。
- 浅色篇不要混暗页；纸底上的字直接压底，不加白框。
- `标题.txt`、`正文.txt` 是逐页文案。原图未随包提供。
