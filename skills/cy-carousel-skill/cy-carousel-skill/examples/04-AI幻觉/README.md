# 例 04｜律师问 ChatGPT「这是真案子吗」→ 什么是 AI 幻觉（AI 科技线）

2023 年纽约 Mata v. Avianca 案：律师交给法院的文书引了 6 个 ChatGPT 编出来的判例，被罚 5000 美元。用一场官司讲清「AI 幻觉」。暗底、电子青强调色，ELIZA 式手排。

![全套预览](全套预览.jpg)

- **节奏**：反差钩子（律师问 AI 这案子是真的吗，它说是）→ 一个看得懂的大例子（6 个假判例、法官命令、律师宣誓书里的 ChatGPT 截图）→ 一句话定义（NIST 原文）→ 为什么会这样（一个词一个词往下猜）→ 三年后还在发生（2149 起）→ 三条编号思考。
- **素材**：全部是一手公开材料。案卷（CourtListener 上的法院命令、宣誓书截图、罚款判决）、NIST AI 600-1（公有领域）、Charlotin 数据库（CC BY 4.0，置顶评论署名）、法官照片（公有领域）。原文纸条从 PDF 矢量渲染，关键词画红圈或下划线。
- **可以学的手法**：聊天截图当证据贴页（04 页）、原话纸条加大号中文译句（05 页）、大字定义页（08 页）、示意对话用下箭头逐行展开（09 页）、整页压暗底图配大数字（10 页）。
- **做法**：`制作.py` 用 `scripts/手排.py`（`S.init` → `Canvas().put()` → `headline/big/body/sticker/label` → `page`）。素材和 research/ 未随包提供，出处见置顶评论。
