# 完美复刻蒸馏写作技能

完美复刻蒸馏技能 v4.0——分析某个作者的多篇文章，双引擎蒸馏： 【思维引擎】提取作者的价值观、世界观、思维习惯 → 【写作引擎】提取词汇、句式、篇章、修辞等7+1维写作风格。 生成「思维+写作风格提示词」+ 可安装的「思维+写作分身子技能」。 分身内置14种写作公式（PAS/SCAR/QUEST/AIDA等），写作时强制执行「双重复检系统」——复检一：文风指纹（词汇/句式/结构/修辞/情感/视角/语气），复检二：思想一致性（立场/情绪/论证/身份/禁忌）。双检通过才输出。 让任何人用这个分身写出的文章，从思考方式到文字表达，都与原作者一模一样。 适用场景： - 你有某个喜欢的作者的多篇文章，想'复制'他的写作能力 - 你想分析为什么某人的文章读起来有辨识度 - 你想创建一个写作分身来批量生产同风格内容（支持不同文章类型） - 你想让分身不仅写得像，还要想得像——思维框架驱动写作内容 - 素材可以来自：公众号合集、小红书合集、微博合集、小说章节、博客文章等 触发关键词： 蒸馏写作风格、分析文风、写作分身、克隆写作风格、复制文风、 风格蒸馏、写作风格分析、模仿XX的写作风格、制作写作分身、 复刻XX、完美复刻XX、克隆XX的写作能力 输入要求： - 单个作者的多篇文章（≥3篇，总计≥2000字） - 支持直接粘贴文章文本 或 提供文件路径 - 文章越多越准，10篇以上效果最佳 更新：v5.0 在v4.0（双擎驱动+女娲质量保障）基础上新增双重复检系统（复检一：文风指纹/复检二：思想一致性），分身输出前双检强制通过。
