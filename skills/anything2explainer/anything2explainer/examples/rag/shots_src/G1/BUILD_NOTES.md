## 结构与复用
- `layout.tsx`：SC01–SC04 共用骨架，**所有状态是绝对帧号 N 的纯函数**（`LLMBlock`/`DashedBox`/`LabelTab`/`Scene1Frame`、`boxAct/boxPast/pastOpacity`、`mixHex`、`Sparkle`）。四个镜头挂同一份代码 → 镜头边界（167→168 等）零跳变；后一镜头直接 import 前一镜头导出的 `BoxNContent`，动画因 N 已过自然处于完成态，并按 `pastOpacity` 淡到 0.5（"灰 = 已过阶段"）。
- ui.tsx 图元：`LLMIcon / DocIcon / Box / Pill / TagBlock / CText / Svg / LineArrow / Cross`；调色 `PURPLE / PURPLE_LIGHT / GREY / GREY_MID / GREY_LIGHT / ORANGE / CORAL / RED_DEEP / WHITE / TEXT_GLOW`；动效 `fadeIn / scaleIn / exitFade / abs`。
- common：`GlitchIn / glitchOpacity / powOutRemain / easeInOutPow / clamp01 / rnd / FONT_HEAVY / FONT_ORB`。
- 组内自补图元：`Sparkle`（四角星）、`Lock`（简笔锁）、`Bubble`（聊天气泡，tail 侧小圆角）、`LoopArrow`（圆弧箭头，头骑在尖端）、`CalPage`（日历页）、`ScaleAt`（定点缩放包装）。

## 关键参数
- 虚线框：`2px dashed`，未激活 `GREY #A0A0A1`，激活 `PURPLE_LIGHT #A175F1` + `0 0 18px 4px rgba(102,45,248,.45)`，填充 `rgba(0,0,0,.42)`（半透明，星点可透，不算不透明黑底）；灰→紫 11 帧线性混色。
- 标签胶囊：骑在框顶边 (x+30, y−17, h34)，24px/700，填色 `#3A3A3A→PURPLE` 随激活度；滑入 Δ40/16 帧。
- 徽章：r17 黑底 + 2px 边，Orbitron 22px/700。
- 入场：缩放 `scaleIn(n,21)` 以元素中心为原点（transformOrigin 写法 B）；滑入 `powOutRemain(n,22,2.5)`；glitch 用 `GlitchIn`（全画幅容器）。
- 循环箭头：`polyline` 72 段，进度 `1−(1−t)^1.8`，头长 20 宽 18，`drop-shadow(0 0 6px rgba(102,45,248,.85))`（本镜头唯一 filter，另有 2 个 DocIcon 的 BLOOM_SOFT）。
- 日历翻页：顶页 `perspective(700px) rotateX(−90·easeInOutPow(2)(t))`，`transformOrigin 50% 0%`，卡 `overflow:hidden`（正向旋转会朝观众放大并溢出，已改负向）。
- 单帧 filter 实例：SC03 ≤ 4（3 DocIcon + 0），SC04 ≤ 4，SC05 ≤ 3；DOM 节点 < 300。

## 对 ui.tsx / 共用层的建议
- `LLMIcon`：`glow` 目前只能开/关固定强度；建议接受字串（自定义 boxShadow）或数值强度，便于做柔光脉冲（本组用外置 halo div 绕过）。
- `Box`：建议加 `overflow?: boolean` 或让 `style` 可控 borderRadius 字串（本组用 `style` 覆盖 borderRadius 做气泡，能用但不直观）。
- 可提升到 ui.tsx 的组内图元：`Bubble`（聊天气泡，第 3 章生成/引用镜头会复用）、`LoopArrow`（循环箭头，第 2 章"增量更新"S20 可复用）、`Sparkle`、`Lock`（权限标签 S19 可复用）、`mixHex`（灰→紫变色是全片通用动效，建议进 common/easing）。
- 磁盘：`$TMPDIR/remotion-webpack-bundle-*` 曾累积 90 个/6.2 GB 触发 ENOSPC，本组已按协议清理 >3 min 的旧包并删除自己的旧 `build_dev_g1_*`；建议各组 still 后顺手清理。当前保留 `build_dev_g1_6`（117 MB）供 QC 复用。
