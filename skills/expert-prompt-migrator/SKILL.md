# 专家提示词迁移工具（Expert Prompt Migrator）

把"在某个工具里好用的专家提示词"变成"在任何 AI 里都能粘贴即用"的通用资产。

> 本技能只提供**方法论 + 原创示例 + 工具**。所有示例提示词均为本仓库原创撰写，可自由使用与改造。请只迁移**你有权使用**的提示词，不要批量抓取他人专有内容。

## 何时使用

- 你在某个平台用过一个好用的"专家"，想把它搬到 DeepSeek / 豆包 / Kimi / Claude / 本地 Ollama 继续用。
- 你攒了一堆零散提示词，想整理成统一格式、可检索的"个人专家库"。
- 你需要从零写一个高质量专家提示词，但不知道结构怎么搭。

## 核心方法论：三步迁移法

1. **提取**：打开原专家的"系统提示词 / 角色设定"，全选复制**完整文本**（不只是标题）。
2. **清理**：删除平台专有语法——占位符（如 `{{用户输入}}`、`{var}`）、内部工具调用指令（如"调用 XX 工具"）、UI 专有标签。替换为通用描述（"用户会提供具体需求"）。
3. **落地**：粘贴到目标 AI 新建对话，等它确认"明白了"后，再发具体任务。

## 三大原则（踩坑总结）

- **清理专有语法**：带着 `{{}}`、工具指令的提示词在别的 AI 里会报错或失准。花两分钟清理，后面省很多事。
- **单专家单任务**：一次只激活一个专家，任务完成再换下一个。三个专家提示词塞一起，AI 会"人格分裂"。
- **补背景信息**：专家提示词是通用模板，你的任务是具体场景。发任务时务必补上：行业、用户画像、目标、约束。

## 五段式提示词结构（写专家提示词的通用骨架）

任何扎实的专家提示词都建议包含这五段，缺哪段补哪段：

1. **角色设定**：你是谁、服务谁、在哪个领域有权威。
2. **专业技能**：你精通的具体能力清单。
3. **工作流程**：接到任务后的标准步骤（先分析→再执行→后校验）。
4. **输出格式**：交付物的结构（表格 / 分点 / 固定模板）。
5. **约束条件**：禁止项、语气、边界（"不编造数据""不用营销话术"等）。

## 迁移自检清单

- [ ] 已删除所有 `{{}}` / `{var}` 占位符
- [ ] 已把"调用 XX 工具"改为"基于你的知识回答"
- [ ] 角色、技能、流程、格式、约束五段齐全
- [ ] 没有平台专有 UI 标签（按钮名、内部模块名）
- [ ] 已为目标 AI 保存为"智能体 / 项目指令"（避免重复粘贴）
- [ ] 已在首次对话让 AI 确认理解，再发具体任务

## 原创示例专家（assets/experts/）

均为本仓库原创，开箱即用，可直接复制粘贴到任意 AI：

- `viral-copywriter.md` — 爆款文案专家（小红书 / 公众号 / 短视频脚本）
- `resume-optimizer.md` — 简历优化专家（STAR 法则重构）
- `data-analyst.md` — 数据分析专家（趋势 / 异常 / 图表）
- `legal-advisor.md` — 法律顾问专家（合同审查 / 风险点）
- `financial-analyst.md` — 财务分析师专家（财报 / 比率 / 估值）
- `english-tutor.md` — 英语外教专家（口语陪练 / 批改 / 纠音）

## 空白模板

`template/migration-template.md` 是可填充的五段式模板。把你的专家知识填进去，就是一个新专家提示词。

## 辅助脚本

`scripts/strip_platform_syntax.py`：批量清理提示词里的常见平台专有语法（占位符、工具调用指令、UI 标签），输出清理后的纯文本。

```bash
python scripts/strip_platform_syntax.py input.md -o cleaned.md
```

## 合规提醒

- 只迁移你**有权使用**的提示词（自己写的、开源协议的、或平台明确允许导出的）。
- 不要将他人专有提示词批量抓取后重新分发——那侵犯版权，也与本仓库定位冲突。
- 改造后的专家提示词可自由使用，但请保留本文件中的方法署名链接（可选）。
