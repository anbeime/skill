# 一键排版-政府公文格式

此Skill用于创建和排版符合中国政府公文格式规范的Word文档。当用户需要生成政府机关、企事业单位正式公文，或说'帮忙排版'Word文档时触发。支持标准公文格式：标题二号黑体居中、正文三号仿宋_GB2312每行28字每页22行、行间距固定值28磅、落款右对齐。排版后生成新文件，命名为'（排版）'+原文件名。
