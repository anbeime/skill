# 文档一致性校对助手

此技能用于自动校对报告、文档中的上下文不一致错误，包括实体矛盾、术语不统一、数据冲突、逻辑时序异常，并提供版本备份和一键修正功能。支持全文或指定章节/页码（多范围）提取校对。当用户说'帮我校对这份报告'、'检查文档前后是否一致'、'找出报告里的低级错误'、'文档一致性检查'时，应使用此技能。
