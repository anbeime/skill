# 海报提示词生成器 (Poster Prompt Generator)

## 核心设计哲学：高维结构化锚定，深度协同风格与色彩画廊

> [!IMPORTANT]
> **【核心准则：全量动态审美决策，严禁写死/机械套用】**
> - **AI 每次实时动态研判**：严禁维护或套用任何“主题关键词 -> 固定风格编号/颜色编号”的静态死板映射（例如严禁一见节气/传统就推 268、一见自然就推 266、一见科技就推 011/054、一见生活就推 018）。
> - **全库开放式匹配**：海报风格与色彩的搭配绝非查表！每次必须由 AI 结合当前海报主题的深层语境、精神内核、视觉隐喻与画面构图，在全库 365 种视觉风格（#001–#368）与 36 种经典主题色（C-01–C-36）中进行**实时、开放式的审美推理与动态搭配**。
> - **激发全库多样性**：同一个主题在不同设计视角下具备多维的美学可能性（如“菜园”既可以是水墨写意、也可以是田园木刻版画、粗粒油画棒、或包豪斯几何构成）。每次推荐都应根据具体切入点构思，充分展现全库 368 种画风与 36 种色彩的丰富生命力。
> - **美学理由具象化**：AI 给出的美学推荐理由必须紧扣当前海报主题的视觉隐喻和画面构图，说明为什么该画风的笔触/质感与该色彩的情绪能完美传达这一主题，杜绝套话。

新一代生图模型（如 GPT Image 2/2.5）在理解了业务场景、受众、渠道和审美风格后，具备极强的原生自主构图能力。**海报提示词不需要长篇大论描写物体细节、机位与光斑，只需精准提供核心业务与设计字段**：

1. **【主题】**：海报核心表达的核心概念或主体文案；
2. **【业务场景】**：具体的投放或使用场景；
3. **【受众】**：目标受众人群；
4. **【内容密度】**：仅填等级：极低 / 低 / 中 / 高；
5. **【情感基调】**：核心情绪与氛围关键词；
6. **【主题色】**：从项目 36 种经典单色（`C-01` ~ `C-36`）中推荐或指定。色彩数量不写死，依据画面层次灵活决定：单色统领（如 `C-01 克莱因蓝`）、双色搭配（如 `主色 C-01 克莱因蓝 + 点缀色 C-28 暖杏仁`）或三色调和；
7. **【editorial风格】**：严格采用标准命名格式，定义海报编辑排版与视觉设计调性，如：`Clean Airy Flat Vector Illustration Editorial 风格`；
8. **【画风】**：完全按项目手绘库经典标准格式注入画廊手绘风格：
   - 风格名称：`#{编号} · {generation_name}`
   - 参考作者/风格名称：`{reference}`
   - 核心风格特征与参考图（**严格按模型能力矩阵动态决定**）：
     - **强作者/强名称激活风格**（如 `#042 Beatrix Potter`、`#011 David Shrigley`、`#002 Saul Steinberg` 等）：模型已对作者名具备深厚语义先验，**出图时只要参考作者即可，严禁输出核心风格特征，也严禁输出参考图**。输出格式为：`风格名称：#{编号} · {generation_name}。参考作者/风格名称：{reference}。`
     - **强特征激活风格**（如 `#276`、`#277`、`#268` 等）：输出 `核心风格特征：{traits}。`，严禁输出参考图。
     - **弱激活/需垫图风格**（如 `#255` 等）：输出 `核心风格特征：{traits}。` 并动态追加参考图路径及隔离声明。
9. **【海报图文一体默认规则】**：海报设计本质上高度依赖文字与画面的拓扑构图。**做海报时不管用户是否显式开启图文模式，默认必须在提示词末尾无条件追加图文模式后缀**：
   `【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】`

提示词内字段严禁添加多余描述性修饰或套话

## 交付规范：画廊推荐卡片 + 8 大纯净设计字段 + 默认图文一体后缀

收到海报设计需求时，**先在提示词上方输出画廊智能推荐组合与美学理由，然后按以下格式输出纯净字段**：

💡 **画廊智能推荐组合**：
- **手绘风格**：#{编号} · {中文风格名} ({English Generation Name})
- **激活决策**：{激活源与免参考图/需参考图/免核心特征判定}
- **经典主题色**：{自由决定单色、双色或三色组合，标明色彩编号与名称及角色（如主色/点缀色）}
- **美学理由**：[1 句说明为什么该画风与色彩组合契合海报主题]
*(若需更换画廊中的其他风格或色彩，可随时告诉我)*
