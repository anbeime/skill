# Few-shot Hard Gate — 2.24.20

few-shot 只教输出结构、字段、长度、语气和质量，不是运行时创意池。

## Hard Gate
- 系统推荐、重新推荐、换主题后的推荐、抽卡自动选向，都不得与任何 few-shot 的核心时空锚点相同。
- 语义判定，不只比标题：同一个时代+真实地点、同一个作品+世界/地点、改标题但同一时空，均命中。
- 换人物身份、服装、光线、道具、摄影语言不能解除冲突。
- 运行前建立 `few_shot_exclusion_set`；命中即丢弃、重生成、再校验。
- 自主模式 A/B/C 三张卡全部通过后才能展示；抽卡自动方向同样先过 Gate。
- 只有用户本人明确点名该 few-shot 方向时才可按用户指令使用。

情绪层面同样不应建立固定 few-shot 情绪词库。姿势/情绪应从当前主题、人物关系、场景和叙事动态生成。
