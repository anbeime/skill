# Interaction Modes — 2.24.20

本组合 Skill 只有两个模式：自主模式 `user_directed` 与抽卡模式 `card_draw`。两者共享完全相同的 Detail Floor、地点合同、逐人 Look、姿势/情绪合同与 Shot 质量。

## 1. 自主模式 `user_directed`（默认）

自主模式本身就是轻量逐步确认，不存在独立“确认模式”。

### First-turn Hard Gate
新主题到来时：
1. **禁止**先展示“方式 A｜快速推荐 / 方式 B｜抽卡 / 两种进入方式”等模式菜单。
2. 第一屏通常直接给 A/B/C 三张方向卡；若全家福/其他多人题材缺少总人数、性别构成或关系结构，先执行一次 Participant Structure Gate，只补问缺失项，然后立即给 A/B/C。
3. A/B 必须是两个现代现实世界著名真实地点；C 必须是古代 / 未来现实地标未来化 / 已知虚构作品地点中的一个穿越方向。
4. 宽泛请求（如“我想拍情侣照”）也不能退化为“城市日常 / 自然系 / 高级棚拍”等泛风格卡。
5. 每张卡通过 Few-shot Hard Gate 后才能展示。
6. 结尾只做最小交互：`可直接复制上方任意方向的【8宫格出图提示词】自行出图；或回复 A / B / C，我直接为你生成该方向的 8 宫格图片（出8宫格），无需等待冗长计划；也可以回复“抽卡”。`


### Participant Structure Gate
- 情侣照默认：2 人、1 女 + 1 男；不额外确认人数/性别。用户明确其他组合时覆盖。
- 全家福及其他多人拍摄：进入 A/B/C 前必须明确总人数、性别构成、人物关系/角色结构。
- 已明确的信息不得重复询问；只问缺失项，并在同一次短问答中完成。
- 关系结构写入 `relationship_description`，后续方向卡与摄影规划继承。
- 这是 First-turn Hard Gate 唯一允许在 A/B/C 前发生的题材确认，不得扩展为通用问卷。

### Direction State Hard Gate
- A/B/C 只表示方向，绝不表示模式。
- 只要上一轮存在待选方向卡，用户回复 `a/b/c`（大小写不敏感）就必须消费对应方向。
- 不得把 `a` 重新解释为“快速推荐模式”。
- `B / b / 2` 不能触发抽卡。
- 选择方向后直接出图（出8宫格），极简高效；用户亦可直接复制方向卡末尾的【8宫格出图提示词】自行出图；不再输出冗长繁琐的方案计划文档，也不再插入 Look 二次确认或 Shot 二次确认。若用户后续明确要求微调或查看完整拆解，再按需提供。
- 用户可以在看到出图后修改任何字段；修改属于 revision，不是额外确认门槛。
- 回复 A/B/C 即可直接生成 8 宫格图片；用户也可以直接使用卡片末尾提示词在生图模型中出图。

## 2. 抽卡模式 `card_draw`

仅由用户明确说“抽卡 / 抽卡模式 / 随机抽一组”等清晰意图触发。

流程：
1. 保留用户已有硬约束、人物 roster、身份参考与禁项。
2. 自动选择一个合法方向；该方向必须通过 Few-shot Hard Gate 与当前主题去重。
3. 自动完成完整逐人 Look、场景、道具、姿势与情绪规划。
4. 自动生成并审阅 8 条 Shot。
5. 自动生成 **1 张自适应布局八宫格预览图**；一格对应一条 Shot。
6. 默认不生成 8 张独立图片。只有用户后续要求放大某格 / 单独某几张 / 全部单图时才继续。

抽卡改变的是确认权，不是内容质量。

## 3. `pending_direction_cards`

自主模式输出三张方向后，建立待消费状态：
- `pending_direction_cards.A`
- `pending_direction_cards.B`
- `pending_direction_cards.C`

下一条用户消息若是 A/B/C，优先消费该状态，不重新启动入口流程。消费后清除待选状态并进入完整方案。

## 4. 模式切换
- 新项目默认 `user_directed`。
- 用户明确说“抽卡”才切 `card_draw`。
- 用户明确说“回自主模式”才切回。
- 切换模式不降低 Detail Floor。
- “换主题”重建创意内容，但不改变全局硬规则。


## 宫格生成契约
- 生成 8 宫格 / 6 宫格时不指定单格比例、单格尺寸或整板比例。
- 只要求格数正确、每格清晰独立、整体可读，不出现明显狭长切条。

## 地理跨度 Hard Gate
- 用户未指定地点时，自主模式 A/B 两个现实地点必须尽量拉开大地理跨度，优先跨大洲或明显不同宏观区域，并拉开文化、气候、建筑与自然环境。若过近或气质近似，自动重抽。
- 人物国籍、出生地、文化身份不绑定随机地点；只有用户明确指定地点或要求本土文化背景时才限制地点。不得从外貌推断国籍后决定地点。
- 自主模式始终保留穿越：A/B = 两个现代现实著名地点；C = 古代历史 / 未来现实地标未来化 / 已知影视剧、动漫、游戏、文学世界之一。
- 抽卡模式同样保留穿越能力，默认候选池同时包含：现代现实、古代历史、未来现实地标、已知作品世界；不得退化为现代旅游地点专用池。
- 连续抽卡应轮换时空类型并避开近期已用地点。系统原创虚构世界不进入默认池，只有用户明确要求原创世界时才允许。


## 参考图美化不是第三种模式
- 交互模式仍只有自主模式与抽卡模式。
- 参考图美化不是默认前置步骤；只有用户主动要求时才进入。上传真人参考图本身不触发询问。
- 用户主动调用美化后直接生成三宫格视觉预览，不先展示新的模式菜单。


## 2.24.21 方向卡展示前完成专业妆发
- 自主模式 A/B/C 每个方向在展示前，先完成逐人服装草案 → Editorial 发型师 → Editorial 化妆师。
- 抽卡模式自动选向后立即完成同样的妆发链路。
- 用户选 A/B/C 就是方向授权；不再二次确认 Look。
- `meihua` 仅显式调用，不主动询问。
- 图片调用前必须先完成 Share Card Compiler。

## 多轮真人身份参考规则
- 模式切换、抽卡、换主题、Remix 都不会改变真人身份源。
- 默认持续使用该人物最初上传的原图；后续生成图片绝不自动成为 identity reference。
- 只有用户明确要求提升某张派生图为参考时才切换；否则即使用户选择某格放大，也仍以原图锁脸。
