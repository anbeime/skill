# Reference Beauty 3-Panel Board

生成一张真人参考图美化三宫格。

要求：
- exactly 3 clear, independent portrait panels
- panels must be easy to distinguish as left / center / right
- same person, same recognizability and age impression
- no text, numbers, captions, logos, watermark
- do not specify panel or board aspect ratio
- 左：清透妆容，去掉斑点/泛红/肤色不均、去黑眼圈；Editorial 发型师设计清爽短发或中短发方案
- 中：白皙柔焦影楼精修，必须同时具有明显淡化斑点/泛红/肤色不均、去黑眼圈、轻微磨皮、柔和柔焦光晕、均匀偏白皙的健康肤色；不得改脸、去龄或塑料皮肤；Editorial 发型师设计最上镜的高完成度肖像发型
- 右：形象强化；Editorial 发型师设计戏剧化形象发型方案
- 差异主要体现在皮肤/气色/妆容完成度/发丝与发型感觉/整体润色，不通过换人、夸张改脸制造差异
- 每格必须由 Editorial 专业发型师基于人物气质、五官重心、头颈比例、妆容和光线设计；可自由变长或变短、变直或变卷，调整分缝、刘海/露额、体积、轮廓和必要发色质感；必须明确刘海策略：保留、改造成具体刘海形状，或露额，并使其服务眉眼、额头比例与人物气质
- 发型探索只用于找感觉，不视为正式拍摄发型锁定

三宫格输出后固定用户提示：
`请选择左 / 中 / 右；也可以直接告诉我你的具体美化需求，例如“提升皮肤白皙度”“去掉所有可见斑点”“修改发型”。如果想一步到位，也可以说“做一版美图秀秀风格精修”，我会据此重新生成预览。`
