# 参考图美化 / 精修身份参考图

## 目标
在正式拍摄前，将用户上传的真人参考图先做一次可视化美化探索，得到一张用户满意、可保存、可长期复用的 **精修身份参考图**。

## 触发
- **仅在用户主动要求时触发**，例如“美化参考图 / 精修参考图 / 做三宫格美化 / 美图秀秀风格精修”。
- 系统看到真人参考图时**不得主动询问是否使用本 Skill**，避免打断自主模式或抽卡模式。
- 未调用本 Skill 不影响正式拍摄：方向阶段的 Editorial 化妆师节点仍会自动处理正式妆面与皮肤优化。
- 已经有用户认可的精修身份参考图时，可直接复用；除非用户主动要求重新美化。

## 用户体验
1. 不展示文字档位。
2. 直接生成 **恰好 3 个清晰独立版本** 的三宫格视觉预览，便于按左 / 中 / 右选择。
3. 三格之间在皮肤、气色、妆容完整度、发丝、发型感觉、整体润色上形成肉眼可感但不过度失真的差异；**至少一格必须提供“白皙柔焦精修”效果**。
4. 用户选左 / 中 / 右后，只放大所选版本，得到高清单张 **精修身份参考图**。

## 三宫格输出后的用户引导
三宫格预览后必须紧接以下用户可见提示，不得只让用户在左 / 中 / 右之间选择：

`请选择左 / 中 / 右；也可以直接告诉我你的具体美化需求，例如“提升皮肤白皙度”“去掉所有可见斑点”“修改发型”。如果想一步到位，也可以说“做一版美图秀秀风格精修”，我会据此重新生成预览。`

- 用户提出具体要求时，先继承身份锚点和未点名的美化条件，只修改所点维度并重出三宫格或指定版本。
- “美图秀秀风格精修”表示更明显的白皙提亮、瑕疵清理、细腻轻磨皮、柔焦光晕、清透妆感与照片精致感；仍不得改脸、去龄过度、塑料皮肤或损失真实毛发纹理。

## 三格内部设计逻辑（仅内部，不必先展示给用户）
- 左：自然修饰 + Editorial 发型师的清爽短发/中短发方案。改善肤色、斑点/泛红/不均、黑眼圈、曝光和气色；发型可不沿用原发长与纹理，以清透、轻盈和五官打开度为准。
- 中：白皙柔焦影楼精修（强制存在） + Editorial 发型师的高完成度肖像发型。在不改脸、不去龄、不做塑料皮肤的前提下，明显淡化斑点、泛红与肤色不均；加入轻微磨皮、柔和柔焦光晕和均匀偏白皙的健康肤色，并完整提升妆容、眼神、腮红/唇色、面部高光与照片精致感；发长、直卷和轮廓可自由重构，以最上镜的气质方向为准。
- 右：形象强化 + Editorial 发型师的戏剧化形象方案。保持身份可识别，但允许更明显地重新考虑妆容完成度、发型长度、直卷纹理、轮廓与整体人物气质，用于寻找更强的摄影形象方向。

## 美化范围
- 整体提亮与清透明亮感
- 肤色均匀，淡化斑点、泛红和肤色不均
- 弱化黑眼圈、适度提亮面部
- 提亮眼神但不改变眼睛形状
- 自然腮红与唇色
- 柔和面部高光与整体色调优化
- 发丝整理、顶部/两侧/刘海/轮廓的适度优化
- 轻微柔焦光晕与写真精致感（中/右更明显，左尽量克制）
- **中格白皙柔焦精修硬性组合**：斑点/泛红/肤色不均明显淡化 + 轻微磨皮 + 柔和柔焦光晕 + 均匀偏白皙的健康肤色；四项缺一不可，且不得牺牲真实毛发、自然面部立体度和人物身份。
- **Editorial 专业发型师设计硬性流程**：每格都先由发型师从人物气质、脸型与五官重心、头颈比例、妆容、肖像景别和光线推导发型，再生成图像。可任意变长或变短、变直或变卷，并调整分缝、刘海/露额、顶部体积、两侧包裹、后区收束和必要的发色质感；原参考图的发长、直卷和发色不构成默认限制。**刘海设计为必填决策**：每格必须选择并写明保留原刘海、改造成具体刘海形状，或露额处理；选择必须服务眉眼、额头比例与整体气质，禁止随机沿用。

## 身份与发型边界
- 三格都必须保持同一人可识别的脸型、核心五官与年龄印象。
- 这里的发型调整主要是 **找感觉**，不等于正式拍摄发型确认；虽然可以自由改变长短、直卷和发色质感，但不能以发型变化掩盖身份漂移。
- 用户选中的放大美化图属于 **derived beauty image**。除非用户明确说“以后用这张作为人物参考/以后以这张为准”，否则它不会替换最初上传原图的 canonical identity reference；正式拍摄仍用原图锁脸。每个正式拍摄主题仍必须经过独立的 Editorial 专业发型师设计。

## 身份参考提升规则
- 选择左 / 中 / 右或执行放大本身不等于切换身份参考。
- 美化结果默认只是派生图；后续拍摄继续以最初真人原图锁定身份。
- 只有用户明确要求将美化结果设为后续身份参考时，才允许显式提升。
