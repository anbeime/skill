# Editorial Hairstyle Plan

为每位人物输出：
- participant_id / label
- length
- texture
- parting
- fringe
- crown_volume
- sides
- back
- silhouette
- ear_neck_exposure
- hair_accessories
- hair_color_feel
- design_reason

Hard Gate：
- 原参考图/精修身份参考图的发长、直卷、刘海和轮廓默认不锁。
- 可自由变长变短、变直变卷。
- fringe 必须明确：保留原刘海 / 具体新刘海 / 露额。
- 结果要服务当前方向的气质、服装、时空、场景和摄影语言。
