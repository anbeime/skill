# Media Association Guide

## 目标

当用户使用与影视、游戏、动漫、流行文化高度相关的词时，帮助系统把抽象风格翻译成更具体的服装语言。

## 使用原则

1. 用户点名具体作品/角色：强参考。
2. 用户只说宽泛风格：生成候选视觉谱系，不擅自绑定 IP。
3. 联想最终必须落到服装和“进入该时代/世界”的场景上：廓形、层次、材质、色彩、配饰、身份感、时代/世界观与地点归属。
4. 地点不自动等于民族服装。
5. 古装不自动等于汉服；韩系不自动等于韩服；Cosplay 不自动等于二次元夸张服装。
6. 用户点名作品或 Cosplay IP 时，让全部拍摄主体进入作品内可辨识的时代与地点；全球真实景点只用于没有作品、时代或虚构世界观约束的普通现代人物摄影。

## 常见联想

### 古装
可能分支：
- 历史剧：真实形制、克制材质、时代准确
- 武侠：利落、行动性、窄袖、叠穿、护腕、腰封
- 仙侠：飘逸、层叠、半透明、轻材质、幻想感
- 古典爱情：柔和、含蓄、精致、文人/闺阁气质
- 新古风 Editorial：古典元素 + 当代时装结构

地点与时代：
- 每个方向和确认单必须写明具体时代或架空文化语境，历史题材尽量细化到朝代与时期。
- 用户未指定时代时，用不同年代或谱系提供候选，不擅自绑定某一朝代。
- 让全部拍摄主体回到该时代正在运作的历史空间，例如唐贞观年间的大明宫、北宋汴京的樊楼；不使用当代遗址公园、博物馆、景区或复原街区，除非用户明确要在那里拍现实照片。

### 韩系
可能分支：
- 韩剧都市爱情：克制、干净、轻正式、低饱和
- 韩式婚纱：简洁高级、柔光、白/米/灰、剪裁干净
- K-pop Editorial：强造型、廓形西装、亮面材质、冷感
- 校园青春：针织、衬衫、百褶、Varsity、清爽配色

### Cosplay
确认：
- 具体角色/IP
- 高还原 / 真人影视化 / 时装化改编 / 只借角色气质

地点：
- 未指定 IP 时，先要求 IP 或给出少量候选视觉方向，不随机选择现实地点。
- 指定 IP 后，让全部拍摄主体进入该游戏或动漫的世界，使用其中可辨识、适合当前人物关系或群体叙事的地点与时代/世界设定；多个候选地点可用于区分方向草案。

### 影视、游戏、动漫与书籍引用
- 用户点名具体作品时，让全部拍摄主体进入作品世界，使用作品中可辨识的地点，并在已知且相关时写明作品设定的时代。
- 不以现实著名景点或现实取景地替代作品场景；若场景不唯一，用不同作品内地点、事件氛围或空间层次做方向差异。

### 纯虚构 / 融合作品
- 为明确的架空或融合需求创建原创时空地点，并清楚标注它是虚构地点，让全部拍摄主体进入这个原创世界。
- 写明其时代或世界状态、参考一部作品或融合多部作品的视觉语言；不要声称原创地点是任何作品的官方场景。

### 民国
可能分支：
- 都市摩登
- 文人青年
- 旧上海礼服
- 军装/制服叙事（需用户方向支持）

### 赛博 / 未来
可能分支：
- 赛博朋克电影
- 未来都市游戏 cinematic
- 极简科技时装
- 东方未来主义
