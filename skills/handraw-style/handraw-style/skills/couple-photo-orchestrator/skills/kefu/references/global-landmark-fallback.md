# Global Landmark Fallback — 世界著名地点随机池规则

此文件不是固定白名单，而是防止默认地点长期重复在少数城市。用户未指定普通现代现实地点时使用。

## 随机步骤

1. 先判断拍摄类型：室外 / 室内 / 私密室内 / 城市旅行 / 自然景观。
2. 根据主题、服装、关系、季节、隐私度构造至少 6 个适配地点。
3. 候选尽量来自不同国家或地区。
4. 随机选 1 个，并立即写成具名地点锚点。
5. 用户要求“换地点 / 再随机”时排除当前地点。
6. 有网页能力时核验名称与当前存在性；许可条件不确定就明确待核验。

### 室内 / 酒店 / 建筑语境
室内优先选择与题材相容的世界著名城市中的具名酒店、历史建筑、公共室内或文化建筑。私房 / 夜景 / 高级室内摄影不应为了“世界著名”强行安排在人流密集的露天景点。

示例类型：巴黎历史酒店、纽约高层设计酒店、东京标志性高层酒店、伦敦历史酒店、威尼斯宫殿式酒店、上海外滩历史建筑酒店等。具体酒店名称若由 Skill 自行提出，必须遵守真实性核验规则。

## 不适用

- 指定影视 / 游戏 / 动漫 / 文学作品：改用作品内具名地点。
- 指定历史 / 古风时代：改用符合时代的历史时空。
- 指定原创虚构世界：改用原创世界具名地点。
- 用户已经明确指定地点：不得随机覆盖。
