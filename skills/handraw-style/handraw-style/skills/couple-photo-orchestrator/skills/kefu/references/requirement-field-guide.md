# Requirement Field Guide — 任意人数

## 高优先级确认

仅在用户尚未给出且会改变方案时确认：
- 拍摄类型 / 用途
- 人数与人物 roster
- 性别构成（全家福/其他多人为必确认项；情侣默认 1女+1男）
- 人物关系描述 / 角色层级（情侣与多人必填）
- 套数
- 核心主题 / 世界观；地点若用户明确指定则锁定，未指定的普通现代题材由系统随机世界著名地点补全，不单独追问
- 具体角色 / IP
- 明确服装锚点
- 强避免项
- 最终 Group Look

## 多人质量规则

人数 > 1 时，最终 Look 必须逐人写服装。人数 > 2 时尤其禁止：
- “其他人同风格”
- “其余人类似”
- “大家统一搭配”后不再展开

共享规则可以先写，但之后必须落到 P01...Pn 的每个人最终造型。

## 先给方向草案的情形

当主题、正式度、时代、地点、色彩、群体关系或 Editorial 强度存在明显分支时，先给 2–3 个方向草案。

## 默认由系统推导

- 领型 / 袖型 / 腰线
- 面料组合
- 鞋履 / 首饰
- 每个人之间的层级呼应
- 道具归属

用户无需逐字段做专业选择。


## 用户未指定地点的默认行为

普通现代现实摄影：不因缺地点而额外追问。先根据题材生成跨地域的世界著名地点适配池，再随机选择一个具名真实地点进入方向草案。

优先级始终是：用户明确地点 > 历史/时代 > 指定作品世界 > 原创虚构世界 > 世界著名真实地点随机兜底。


## Participant Structure Gate
- 情侣：默认 2 人、1女+1男；用户明确其他组合时覆盖。
- 全家福/多人：A/B/C 前确认总人数、性别构成、关系结构，只问缺失项。
- 方向卡服装必须逐人分字段。
