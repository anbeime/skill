# Universal People Photo Requirements Planner

原 Couple Photo Skill 已升级为任意人数人物摄影需求与造型规划。

支持：单人、情侣、家庭、朋友、婚礼派对、团队、乐队、古装群像、Cosplay 群像等。

核心变化：
- 人物从固定 `female / male` 改为 `participants[]`
- 每人有稳定 `Pxx` ID
- 每套 Look 必须逐人写完整服装
- 人数增加只允许文档变长，不允许单人描述缩水
- downstream Shot 必须明确本格出镜人物与逐人动作
- 旧双人 schema 仍可读取

详见 `SKILL.md`。


## 2.24.20 入口规则
- 普通聊天不要求先提供项目目录。
- 自主模式首轮默认输出 A/B/C 三张时空方向卡，不先展示模式菜单；全家福/其他多人仅在缺失人数、性别构成或关系结构时先做一次紧凑人物结构确认。
- A/B 为现代现实世界著名地点，C 为穿越方向。
- 用户选 A/B/C 后直接生成完整 Look 并继续姿势/情绪与 8 Shot。
- 抽卡只由明确“抽卡”指令触发。

- 情侣/多人方向卡含独立“人物关系描述”，服装必须按每位人物单独分字段输出。


## 2.24.20
每个方向卡形成逐人服装草案后立即进入 Editorial 专业发型师设计，再进入 Editorial 专业化妆师设计；A/B/C 展示时妆发已定稿，用户选向后下游只继承。精修身份参考图里的妆发只做审美参考。
