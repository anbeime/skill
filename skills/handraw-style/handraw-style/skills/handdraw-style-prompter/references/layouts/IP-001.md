IP Positioning Card.
Core purpose: Answer why the IP exists and define its commercial and emotional positioning.
Card content: IP name (Chinese/English), one-sentence positioning (identity + core value + emotional effect), 3 core tone tags, target audience profile.
Composition: Full-body primary character displayed prominently in the center or off-center, with small annotated callouts highlighting its visual signature, paired with large bold typography for the name and positioning slogan, with generous whitespace and a brand cover feel. Solid-color clean background.
High internet presence, highly generalized silhouette, restrained color palette: clean lines if 2D, restrained materials, accessories, and ornaments if not 2D. High recognizability even at thumbnail scale.
Default workflow: Analyze design requirements from the theme, design visual metaphors first, then design a fun IP character.
Default style: 2D doodle / sketch style; if a specific style is designated, prioritize the designated style.
Default IP character: Non-human mascot character.
Avoid: Extraneous props (unless they are a fixed part of the IP character), atmospheric decorative elements unrelated to the IP.
Theme: {theme description}, please design a fun IP character for me.
