【画幅比例驱动切分原则（严禁死板切分，完全由目标比例决定）】：
1. 竖版画幅（如 3:4、9:16、1:2 等纵向构图）：默认采用【上下 1:1 纵向堆叠双拼】。上方摄影区（占 50%），下方艺术转译区（占 50%），顺应手机端自上而下的视觉阅读动势与故事自然向下延展；
2. 横版画幅（如 16:9、4:3、5:2、21:9、2.35:1 等横向构图）：默认采用【左右 1:1 横向并排双拼】。左侧摄影区（占 50%），右侧艺术转译区（占 50%），顺应横向视觉扫描序列，两侧均呈现方正/垂直的独立艺术杂志跨页质感；
3. 方版画幅（1:1）与自由画幅：根据主体姿态动势与延伸线走向自适应（垂直动势采用上下拼，水平延展采用左右拼），亦可采用对角斜切或完全服从用户显式指定的分割方向。

【真实摄影区（竖版上方 / 横版左侧）】：
由生图模型根据主题生成超写实、高质感的单反摄影真实照片（若用户上传了参考图则以原图为准）。严格保持原始宽高比例与构图完整性，严禁拉伸变形。保持摄影真实景深、自然环境光线、真实皮肤/毛发质感与抓拍现场氛围，不做任何插画化处理，作为风格转译前的真实摄影基准。

【艺术转译区（竖版下方 / 横版右侧）—— 彻底去写实、大面积留白与专属构图类型】：
1. 彻底去写实化与画风从零重绘（坚决杜绝照片套滤镜）：
艺术转译区必须与摄影区形成极具视觉冲击力的跨媒介反差！坚决不要在原照片的写实五官与体积光影上套滤镜。必须“只提取摄影区人物/主体的标志性特征、姿态神态与大轮廓”，在画风上完全按所选风格从零重绘为纯粹的 2D 手绘/艺术插画，让所选风格的笔触、线条、专属配色与质感辨识度最大化释放。

2. 坚决彻底剔除原片环境杂质（四周留白是第一原则，严禁照抄全景背景）：
严禁把摄影区的杂乱背景机械复制到转译区！转译侧画面四周边缘必须保留充足、干净的 40%–80% 负空间/呼吸留白底色（暖象牙白、米白棉麻纸纹），主体与文字向内部收拢，绝不贴边、绝不爆框。

3. 七大核心转译类型体系（每次输出单义明确，并在文末附带编号清单供用户点选）：
AI 在生成提示词时，若用户未指定类型，可默认选择最契合画面主题的 1 种类型（或按顺序轮替），并严格输出单义执行指令；同时必须在输出末尾附带 7 种可选类型清单（含编号），方便用户随时切换：

- 【类型 02 · 撕纸裂变第二世界型 (Torn-Paper Second World)】：接缝处采用不规则手工物理撕纸毛边。现实世界穿透撕纸后进入“第二世界”，物理规则发生超现实突变（水变成可拉扯布匹、光变成被托起实体、影子变成可攀爬阶梯），暖象牙纸大面积留白，搭配克制照片碎片拼贴与极简小人；
- 【类型 03 · 越界破框型 (Boundary Break / Out-of-Bounds)】：在纯白/暖纸底色中设置单枚低饱和几何色块/容器，主体大部分在色块内，但关键部位（头部、手臂、枝叶）自然突破色块边缘伸出，形成空间穿透感；
- 【类型 04 · 微缩浮岛型 (Miniature Diorama / Floating Island)】：主体大幅微缩为占画面 10%–25% 的精致纸面小景，由一抹清淡色带或微型基座承托，四周呈现大片静谧空旷留白；
- 【类型 05 · 记忆图谱平铺型 (Memory Knolling / Fragment Collage)】：居中放置手绘主体，留白中错落平铺 3–6 枚提取自原图的记忆特征小插画/贴纸（带 NO. 编号），间距透光，图鉴手账感；

- 【类型 07 · 正负形咬合型 (Gestalt Positive-Negative Interlock)】：主体高度提炼为几何剪影，与背景正负形相互转换咬合。

4. 编辑式微排版（文字优雅嵌入负空间）：
