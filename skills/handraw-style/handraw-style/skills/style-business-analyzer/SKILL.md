# 风格商业应用分析器 (Style Business Analyzer)

本 Skill 是手绘风生态中将**艺术视觉语言转化为高价值商业资产**的专项策略引擎。
通过深度剖析全库 365 种手绘与写实风格的底层视觉基因，推演其受众心理学机制、传播穿透力与溢价空间，为品牌联名、实体文创周边、新消费包装、自媒体起号与广告营销提供出版级、可直接落地的《风格商业应用指南》（归档于 `business/{number}.md`）。

---

## 🎯 核心使命与触发场景

当用户提出以下需求时启动本 Skill：
- **单风格商业洞察**：“分析风格 FI-001 的商业应用”、“这个风格适合做什么生意？”、“给 018 写一份商业应用指南”、“这个画风怎么商业变现？”；
- **行业/品类找风格**：“做精品咖啡杯套推荐什么画风？”、“宠物文创周边适合哪些风格？”；
- **商业库审计与批量补齐**：“检查哪些风格缺少商业指南”、“补全 FI 系列的商业文档”。

---

## 🏛️ 权威数据源与协同机制

本 Skill 深度协同底层 3 大元数据库：
1. **风格元数据**：[`styles_200_reorganized.md`](../../styles_200_reorganized.md) 与 [`references/styles.json`](../handdraw-style-prompter/references/styles.json)（提供风格编号、原参考作者、生图英文名、核心特征与视觉语言）；
2. **排版版式库**：[`references/layouts.json`](../handdraw-style-prompter/references/layouts.json)（全库 167 种社媒卡 `SC-*`、信息图 `IG-*`、分镜 `SB-*`、IP卡 `IP-*`、电商 `EC-*`）；
3. **经典色彩库**：[`references/colors.json`](../handdraw-style-prompter/references/colors.json)（全库 36 种经典主题单色 `C-01` ~ `C-36`）；
4. **输出归档目录**：`business/{number}.md`（如 `business/FI-001.md`，每个风格对应唯一同名 Markdown 文件）。

## ⚙️ 质量契约与防污染铁律

1. **绝对禁止示例画面污染**：
   牢记全局铁律，商业应用指南必须聚焦于该风格的**通用视觉语言**与**商业心理机制**。严禁将测试图或参考图中的具体人物、服饰、花草、道具作为该画风的既定属性写入商业报告。
2. **物理载体与商业闭环**：
   单品必须指明具体材质（如特种水洗牛皮纸、350g触感纸、光影亚克力、纯棉重磅等），文案隐喻必须击中目标客群情绪。
3. **本地归档同步**：
   生成完成后，必须将完整内容写入 `business/{number}.md`，并执行校验：
   ```bash
   python scripts/generate_style_business.py --style {number}
   ```
