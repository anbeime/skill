# 踩坑清单（都已写进脚本的默认规则）

## 整体（两条路线通用）

| 坑 | 表现 | 解决 |
| --- | --- | --- |
| 每期歌词像上一期 | 「隆中一张图」「X 说完了 Y 就上场」又出现 | 写之前读往期歌词，逐句查重（lyrics-guide.md） |
| 气氛组 / 观众镜头太多 | 抢戏、空台子 | 不做固定气氛组；观众只在开场、间奏、片尾；镜头留给台上两人的动作 |
| 唱的人在左、两人换边 | 观众看晕 | 固定站位：A 永远左、B 永远右，单人镜头朝向也固定 |
| 间奏拼接有停顿或「卡一下」 | 口号和下一句之间断开 | Suno 常在口号后自己连唱下一段的第一句：保留这段原样过渡，在它「后面的换气处」跳到正式段落里同一位置（相隔整数小节），`retrim.py --keep ...`。不要留静音、不要非整拍偏移 |
| 句开头算到上一句的尾字上 | 字幕早出、切的人声开头多半个字、结尾少一个字 | analyze_song 只认本小节 -0.13 秒以后的字，跳过上一句尾字；切人声从开口切到下一句开口前 |
| 生僻字 Suno 念错 | 「上邽」 | Suno 那栏写同音字（上圭），字幕用原字 |
| 场景图是斜的 | 开场推镜头对不正 | 场景提示词开头写死正面对称平视，结尾 `--no` 斜角 |
| AI 皮肤像打了蜡 | 胶质感 | 调色 B：压高光、降饱和、自适应锐化、加颗粒（package.py 默认） |
| 字幕 / 注释看不清 | 注释太小太淡 | 金色 (255,228,92)、注释特粗纯白 + 白色柔光 + 底部渐变暗底 |

## Seedance 网页版

| 坑 | 表现 | 解决 |
| --- | --- | --- |
| 提示词只写歌词不写时间 | Seedance 照文字自己重念，嘴乱 | 每半句写「X.XX–X.XX 秒「……」」，seedance_packs.py 自动量 |
| Seedance 按自己的节奏重唱 | 每句早晚 0.1–0.6 秒、越唱越慢、唱重字 | seedance_align.py 逐镜头拟合偏移 + 速度 |
| 某段多唱一整句 / 漏唱半句 | 后半段嘴全错 | 重做那段；用户说没事就 `--whole` 整条放 |
| 「对口型」说音频不符合平台规则 | 整段过不了审 | 拆单句试，找出被审核的词 |
| 转身 / 远景脸变形 | 片尾、狼顾镜头换了张脸 | 近景、半身图 + 表情近照、机位不动、不走路 |
| DJ 台是空的 | 定妆图做了却没传 | 每段都传 DJ 图并写「DJ 台上始终有人」 |
| 2K 用重新生成 | 时间全变，对齐作废 | 用「超清」放大同一条 |

## H3 路线

| 坑 | 表现 | 解决 |
| --- | --- | --- |
| 参考图用全身三视图 | H3 拍成全身远景，脸小，看不清口型 | 近景用裁出来的半身图，提示词第一句写景别 |
| 一条给两句歌词 | 第 2 秒后 H3 自己重唱，嘴对不上 | 一条只给一句 |
| H3 把歌晚放 0.1–0.3 秒 | 自动检查看起来全红 | qa.py 先整句搜偏移，h3run 自动存进 shifts.json |
| 纯侧脸、麦克风挡嘴 | 口型看不出 | 唱的人 3/4 侧脸，麦拿低 |
| 说唱时手里没麦 | 穿帮 | 提示词写明右手始终拿麦 |
| 圈里站一排群演 | 像士兵列队 | 写明圈里不站人 |
| 道具变形（羽扇变折扇） | 前后不一致 | 尾部写死道具材质和形状 |
| 观众镜头台上是空的 | 对唱时台上没人 | M10 写明两人在圈里、谁在唱 |
| 气氛组出现太多 | 群演抢戏 | 全片最多 3 次 |
| 同一个镜头切三段连放 | 一卡一卡 | 中间插别的镜头 |
| 按嘴型测量结果挪画面 | 有一次挪 0.58 秒反而错 | lipcheck 只作参考，挪完给用户看，说原来对就改回 |
| 字幕提前 | 每句早 0.4–0.8 秒 | 句起点只算落在本小节的字，跳过上一句溢出的尾字 |
| 识别在前奏里幻听出字 | 歌词段落找错位置 | 用前 4 句歌词去匹配识别文字定位 |
| 调色太重 | 成片暗 30% | 只加一点对比和颗粒 |
| 本地改口型（LatentSync） | 装得上，但用户觉得不如原版 | 不用 |
| 发文件到手机 | 超过 30MB 只能在电脑上看 | package.py 同时出手机预览版 |
| ffmpeg drawtext 崩溃 | 缺 fontconfig | 文字全用 Pillow 画成 PNG 再叠 |
| Windows 上 `python3` | 是微软商店占位程序 | 用 `python` |
