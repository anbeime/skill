# 分镜模板

## Seedance 路线（默认）：照「吕布 vs 赵云」那类爆款的节奏

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–2.5 秒 | 开场 | 观众身后机位，前景虚焦的手和火把，两人台上对峙，镜头缓慢前推；标题直接叠在画面上，没有单独标题卡 |
| 2.5 秒 | A 第 1 句 | 直接开唱，弹名字卡 |
| A 16 句 | 4 段 × 4 句 | 一句一个镜头：半身近景 → 双人中景 → 近景仰拍 → 过肩，动作照字面演；听的人有反应 |
| 约 2.5 秒 | 间奏 | 观众齐喊口号，最后看到 B 举起话筒 |
| B 16 句 | 4 段 × 4 句 | 同上；B 的名字卡在右边 |
| 约 7 秒 | 片尾 | B 得意、A 无奈，叠「下一场你想看谁的对决？」 |

规则：A 永远在左、B 永远在右；观众只在开场、间奏、片尾；不做气氛组；每句都有动作；字幕最后两字放大垫红笔刷，下面一行史料注释。

## H3 路线（可选，按 API 计费）：原片拆出的 35 条模板

`scripts/make_clips.py` 按这份模板自动生成每条素材的提示词和剪辑表，下面是给人看的版本。A 是先唱的一方，B 是后唱的一方。

## 原片的拍法规则（每条提示词都带上）

- 双人镜头里**正在唱的人站画面左边**：A 那段 A 在左，B 那段机位换边、B 在左
- 开场是全景快推、越过 B 的肩膀落到 A 身上（A 在右）
- 正面镜头背景都是虚化的 DJ 台、蓝白灯管、红灯笼；主光来自头顶追光
- 平视、35–50mm、轻微手持；只有两段收尾用低机位或猛推
- 听的人拍反应：正面淡定，或侧脸咬牙，前景有对方虚化的手或道具
- 观众背影镜头里**台上必须有人**；气氛组全片最多 3 次；同一个镜头不能连着出现

## 每条提示词的组成

素材说明 → 景别规则（近景）→ `Cinematic photoreal shot, 16:9.` + 运镜句子 → 站位 → 声音规则 → 3/4 侧脸 + 拿麦 → 场景 → 尾部（人物一致、道具写死、不要字幕水印）。全部由脚本拼装。
