# agent-or-not

复杂任务执行前的 Harness 就绪度检查技能。基于 Harness Engineering 理论，在复杂任务（涉及多步骤/多模块/长链路/不可逆操作）启动前主动触发，检查当前上下文与记忆中是否已具备足够的执行 harness——目标边界、约束规矩、上下文记忆、工具能力、验证方案。若 harness 齐全则进入 Agent 模式高置信执行；若 harness 缺失则启动补齐机制（检索记忆 → 向用户反问获取关键 harness 信息），避免在'模型模式'下裸奔导致返工与失控。触发场景：复杂任务、长链路开发、多阶段项目、涉及外部系统/工具的操作。用户触发词：「你是 Agent 还是模型」「检查 harness」「agent-or-not」「先确认准备度再开始」。
