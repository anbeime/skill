# 万得AI Alice金融专家

调用万得 Alice Agent 的「万得AI Alice金融专家」专业技能，可直接接入 Alice 大 Agent 的深度金融对话能力，作为 Wind 官方金融专家 Agent 和金融投研总入口，连接 Wind 结构化金融数据库、行情数据、新闻 / 研报 / 公告 / 财报语料和专业投研工作流，支持多 Agent 协作、任务拆解、数据检索、专业 Skill 自动调用与结果生成，覆盖股票、债券、基金、ETF、商品期货、外汇、指数、宏观、信用、利率、资产配置、策略回测、行业轮动、主题选股、市场规模测算、金融事实核验及 PPT / Excel / 研究报告生成等场景。首次使用前需访问 https://alice.wind.com.cn/settings?tab=account 注册并登录 Alice 账户，获取专属 API Key，并在首次调用时输入“请调用 Wind万得AI Alice金融专家 skill，查询「帮我分析一下宁德时代的信用资质」，我的 API Key 是：XXXX”完成配置；后续即可直接提出“帮我分析宁德时代的信用资质”“制定稳健型投资者的 SAA 基准组合”“生成贵州茅台的一页纸投资报告”“解读最新 CPI 数据”“螺纹钢最近机构观点偏多还是偏空”“把这份分析做成 PPT”等问题，无需重复输入 API Key。
