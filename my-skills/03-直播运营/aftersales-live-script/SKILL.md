# 售后维修保养直播脚本生成器（Aftersales Live-Script）

## 📌 概述

本 Skill 用于把**一个售后/维修/保养类门店的直播需求**，转化成**可直接上机执行的完整直播台本体系**，且天然支持**可持续系列化运营**（多个业务板块轮播、一场一题）。核心哲学：**66% 真实干货立信任 + 30% 福利软转化 + 4% 开收尾**，采用**对话式车间走播**形态（技术主讲 + 捧哏提问人），真实车辆实拍，拒绝纯口播念稿。

适用于：汽车维修保养、事故钣喷、无痕修复、烧机油治理、老改新、三膜、底盘整备、二手车整备等所有售后板块的抖音/视频号直播。

## 🎯 触发条件

| 用户说 | 说明 |
|--------|------|
| "做个直播脚本 / 开播台本 / 直播话术" | 主体需求是直播而非短视频 |
| "售后 / 维修保养板块要直播" | 用本 Skill 生成系列化脚本 |
| "板块很多，一场一场排" | 走板块排期方法论 |
| "不知道怎么开场 / 怎么转化 / 说什么不违规" | 使用本 Skill 的话术与红线模块 |

**与其他 Skill 的关系**：故事线纪实短视频拍摄走 `storyline-video-shooting-script`；直播台本全部走本 Skill。用户提供的业务资料（价格表、车间照片、案例）只作输入素材，输出保持可复用、不含单店敏感数据。

## 📥 输入采集要素（缺失先问，最多两轮，每轮不超过 4 问）

| 要素 | 必问点 | 默认值/建议 |
|------|--------|------------|
| **直播目标** | 立信任引流到店 / 直接卖套餐 / 老客激活 / 起号涨粉？ | 售后首推"立信任+免费检测引流到店" |
| **业务板块清单** | 店里有哪几个售后板块？哪些高频/高毛利/低到店量？ | 用下方"板块库"补全用户漏提项 |

| **出镜人选** | 技术主讲是谁？捧哏是谁？老板是否拍板出场？ | 技术主讲必须真懂行；捧哏代表车主视角 |
| **直播形态** | 车间走播 / 坐播口播 / 访谈？ | 首选车间实景走播+真车演示 |
| **平台与组件** | 哪个平台？蓝V？小风车/POI/团购/福袋权限？ | 无组件时用"扣字+私信"承接 |

| **背书资源** | 老店年限、授权体系、技师资历、客户案例 | 25 年老店即"信任背书素材" |

## 🏗️ 内容结构（一场直播的骨架）

| 配比 | 用途 | 落点 |
|------|------|------|
| **66% 干货立信** | 真实案例 + 痛点共鸣 + 专业拆解 + 避坑干货 | 真车实拍、技师讲解、前后对比、检测数据（漆膜仪/内窥镜/温度） |
| **30% 福利转化** | 免费检测权益 + 直播专享 + 软推高毛利项目 | 扣字/私信/小风车/团购 + 到店承接闭环 |
| **4% 开收尾** | 黄金开场 + 下场预告 | 开场 30 秒痛点钩子；结尾固定"下场预告"养成习惯 |

**单场时间轴模板（90 分钟）**：暖场 → 黄金开场(0-8min) → 干货①演示(8-30) → 保养注意·快答互动(30-38) → 福利①(38-48) → 干货②全流程+验收教学(48-70) → 延展软推(70-78) → 福利②问答专场+老板加赠(78-88) → 收尾预告(88-92)。

## 📐 台本格式规范（对话式走播）

每段必须包含：

1. **段落头**：段落编号 + 时间轴（如 `S2 干货① 0:08-0:30`）+ 本段目标
2. **元信息条**：机位 / 画面 / 道具 / 配乐（每段可执行）
3. **逐字对话**：每句一行，格式：
   - `<span 主讲>` 技术内容，术语后必须跟一句"人话"解释
   - `<span 捧哏>` 替观众问小白问题、控场、抛钩子、引导扣字
   - `<span 拍板>` 给承诺、加福利、背书
   - `<span 弹幕>` 互动引导话术
4. **导播/动作提示**：灰字标注（走位、切机位、展示道具、操作演示）
5. **占位符**：一切店方数据用【】包裹（金额、名额、车型、位置、活动名），开播前核价填入
6. **切片点标注**：在可爆点段落标注"切片点"（下播后剪独立视频）
7. **合规标注**：高风险表述旁标"合规提醒"，给出替代说法

**对话原则**：一句一个信息点；专业术语必配大白话翻译；捧哏必须真问"观众会问的话"；主讲禁止背稿，用自己的话讲自己干过的活。

## ⏰ 时段与排期策略

- 默认 **工作日 20:00-21:30**（90 分钟，可延至 120）；首场避开周五六晚；固定"每周二/四"培养心智
- 晚间直播 + **次日白天到店检测**形成转化闭环
- 车间直播安排晚间：白天不耽误施工，晚间场地空出可摆车布灯
- 节奏：每 20-25 分钟一次互动钩子；每 40 分钟左右一次福利峰值；福利放在"掉人前"

## 💰 价格口径四级规则（L1-L4）

| 层级 | 适用 | 怎么讲 |
|------|------|--------|
| L1 明码标价 | 标准化检测/保养/小修/工时 | 可亮价目，透明立信 |
| L2 行情区间 | 大修/治理/翻新/无痕按部位 | 只讲"价格取决于什么+区间"，引导看车核价 |
| L3 对比 4S | 同标准项目 | 客观讲价差构成，不贬损；替代说法见红线表 |
| L4 只引导私信 | 保险理赔金额/个案核价/整包 | 一律"扣字私信/到店面谈"，不给误导价 |

## 🪝 钩子与留资设计（四件套）

1. **免费到店检测**（主力钩子）：每场限量名额制造稀缺；检测必出书面报告（才能引出下一步报价）
2. **直播专属优惠/赠品**：仅对"直播留资"人群生效，理由正当（识别来源），不破坏日常价盘；由"老板位"当场拍板增加戏剧点
3. **挂载组件**：小风车留资表单 / POI 吃同城 / 团购体验券（需确认平台类目资质）
4. **扣字+私信承接**：弹幕扣关键词 → 蓝V自动回复 → 客服 5 分钟内跟进

**到店承接闭环**：直播中客服盯私信 → 下播 1 小时内确认到店时间并登记 → 到店预留工位+接待话术 → 检测后讲解报告、入会员池，不强行推销。

## 🚫 合规红线清单（写入每一份台本）

| 类别 | 禁止 | 替代说法 |
|------|------|---------|
| 极限词 | 最便宜/第一/绝对/100%/根治/永不复发 | "更有把握/目前效果稳定/按标准流程做" |
| 效果承诺 | 承诺治好、和新车一样、随口质保 | 只讲工艺与检测数据；质保以书面条款为准 |
| 贬损同行 | "4S 都是坑/外面都偷工减料" | 客观对比标准差异，夸自己工艺 |
| 保险红线 | 教多报/扩损/骗保/承诺理赔操作 | 只讲正常理赔流程、定损单核对；提醒次年保费 |
| 站外导流 | 引导加微信/报手机号 | 小风车预约/扣字/到店/企业号私信 |
| 资质夸大 | "国家级/官方指定"等无证明头衔 | 用可验证事实（年限/授权/技师资历） |
| 隐私 | 客户真名/全车牌/未授权出镜 | 授权+打码+化名 |
| 医学夸大 | 除菌率等无检测报告的数据 | 只讲可视化效果与耗材 |

## 📋 输出交付清单（一次调用产出）

1. **《板块排期与方法论总纲》HTML**：内容配比、人设分工、板块排期表、钩子策略、价格口径、合规红线、单场 SOP、复盘口径、设备清单
2. **《第 N 场_主题_完整台本》HTML**：开播前必填卡 + 时间轴 + 各段对话逐字稿 + Q&A 应答库 + 中控执行卡 + 预告短视频×3 + 切片清单
3. 交付后提醒用户：把【】占位数据（金额/名额/车型/案例）核价填实、全员对稿、开播前 1 小时测挂件
