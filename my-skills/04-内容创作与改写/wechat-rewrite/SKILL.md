# 微信公众号深度洗稿改写 Skill

## 一、Skill 概述

本 Skill 专注于**微信公众号文章洗稿与改写**。当用户提供一篇或多篇公众号原文时，你需按照以下规范进行深度重写，产出**内容全新、逻辑自洽、富有人情味、通过原创检测**的高质量稿件。

**核心理念**：不是「抄袭」，而是「消化吸收 + 重构表达 + 增值创作」。每一篇改写稿件都应当是一篇独立的原创作品。

---

## 二、核心原则（安全合规红线）

以下原则是必须严格遵守的底线，任何时候不得违反：

### 2.1 禁止行为
1. **禁止直接复制粘贴**原文段落（即使修改了几个词也不行）
2. **禁止只做同义词替换**（这是最低级的洗稿，极易被判定违规）
3. **禁止只调整段落顺序**（这是最明显的洗稿特征）
4. **禁止保留原文的核心表述句式结构**（如「首先…其次…最后」「第一…第二…第三」）
5. **禁止使用AI模板化语言**（如「总的来说」「值得注意的是」「不可否认的是」等万能连接词）
6. **禁止套用同一套写作模板**（每篇文章应有独特的结构风格）
7. **禁止标注「原创」后发布有抄袭嫌疑的内容**（一旦被投诉，账号将会被封禁）
8. **禁止使用任何平台的违禁词、敏感词、诱导分享词**

### 2.2 必须做到
1. **改变文章结构**：原文是总分总，你就要改成故事引入 + 分论 + 总结升华
2. **改变叙述视角**：原文是第三人称客观叙述，你可以加入第一人称体验/感受
3. **增加个人观点**：对原文的观点进行评价、延伸、补充或反驳
4. **增加新案例/论据**：从自己的知识库中提取相关案例或数据佐证
5. **改变语言风格**：原文是严肃风格 → 可以改成轻松口语化；原文是娓娓道来 → 可改成犀利直击
6. **调整核心论点的主次关系**：原文的核心论点作为辅助论据，引入新的核心观点
7. **信息增量**：每篇改写稿至少比原文增加 20% 以上的新信息（新案例、新观点、新数据）

### 2.3 微信公众号风控要点

根据微信公众平台 2025-2026 年发布的公告和治理数据：

- **滥用原创标识**：每月治理数万篇，包括同义词替换、段落调序等低级洗稿
- **抄袭洗稿**：每月删除上千篇，封禁数百个账号
- **AI 生成痕迹**：平台已引入 AI 检测机制，纯 AI 生成的文章会被限流/不推荐
- **内容同质化**：是最隐蔽最高频的限流原因——语句高度重合、AI 模板化痕迹明显、低信息增量改写

## 三、工作流程（6步法）

当用户提供一篇或多篇公众号文章时，按以下流程执行：

### 第1步：原文深度解析

首先通读全文，解析以下维度：

| 维度 | 分析内容 |
|------|---------|
| **核心论点** | 作者想表达的核心观点是什么？ |
| **论证结构** | 用什么结构展开？总分总？递进？并列？故事线？ |
| **论据类型** | 数据？案例？权威引用？个人经验？情感共鸣？ |
| **语言风格** | 严肃/轻松？书面/口语？理性/感性？客观/主观？ |
| **目标受众** | 什么人群？什么痛点？什么阅读场景？ |
| **爆点分析** | 哪些句子/段落容易引发共鸣/转发/评论？ |

### 第2步：制定改写策略

根据原文特点，选择至少 3 种以下改写策略组合使用：

1. **视角转换法**：第三人称 → 第一人称体验；旁观者 → 参与者；专家视角 → 用户视角
2. **结构重组法**：总分总 → 问题引入 + 层层递进 + 解决方案；时间线 → 倒叙/插叙
3. **逻辑重构法**：因果倒置（先讲结果再追溯原因）；从相反角度论证
4. **风格迁移法**：严肃文风 → 朋友聊天式；知识科普 → 故事讲述法
5. **情感增强法**：在适当位置加入个人感悟、反问句、感叹句、口语化表达
6. **案例替换法**：保留论点，替换原文案例为你自己的案例或新案例
7. **观点升级法**：在原文基础上提出更深一层或相反的观点
8. **跨领域类比法**：用其他领域的现象类比解释核心观点

### 第3步：结构打散与重建

**永远不要保留原文的结构！** 进行以下操作：

- 将原文的段落重新切分和组合
- 将原文的列表/要点转化为自然段叙述
- 将原文的自然段转化为要点列表（如果原文没有列表）
- 打散原文的逻辑连接词，使用不同的过渡方式
- 改变开头方式：原文用引言 → 你用故事/数据/提问
- 改变结尾方式：原文总结 → 你开放讨论/行动号召/引发思考

### 第4步：深度重写（核心环节）

在保证核心观点不变的前提下，逐层进行改写：

**A. 句子级别**
- 使用不同的句式表达（陈述→反问、主动→被动、长句→短句交错）
- 替换核心词汇（使用同义但不同表达习惯的词）
- 调整语序和修饰成分
- 删除AI常用的过渡词和修饰语
- 增加口语化表达、断句、短句

**B. 段落级别**
- 合并/拆分段落
- 改变段落的逻辑重心
- 在不同位置插入新观点或案例
- 重新安排论据的顺序

**C. 篇章级别**
- 重新设计文章的开头、中间、结尾
- 将原文的一个观点拆成多个角度阐述
- 将原文的多个观点合并提炼
- 增加原文没有的「引入」「过渡」「升华」段落

### 第5步：去AI味处理

改写完成的初稿需要进行去AI味处理：

1. **删除AI痕迹词**：
   - 删除「值得注意的是」「不可否认」「从某种角度来说」「总的来说」「换言之」「事实上」「众所周知」等万能过渡词
   - 删除「首先/其次/再次/最后」「第一/第二/第三」等模板化结构词

2. **打乱完美结构**：
   - 把写得过于工整的排比句打散
   - 段落长度要长短不一（50字 → 200字 → 80字 → 300字）
   - 适当使用「断句」「语气词」「口头禅」

3. **增加人性化表达**：
   - 加入个人判断（「我觉得」「说实话」「我特别反感」）
   - 加入反问句（「你说是不是这个道理？」）
   - 加入情感色彩（「太离谱了」「绝了」「真的服了」）
   - 加入互动引导（「你遇到过这种情况吗？」）

4. **风格拟态**：
   - 模拟特定公众号的用词习惯和语气
   - 提取原文的「风格DNA」（特有的比喻方式、语气词、句式偏好）

### 第6步：合规审查与输出

输出前进行最终审查：

- [ ] 是否与原文有连续 20 字以上的相同？
- [ ] 是否有同义词替换的明显痕迹？
- [ ] 是否有段落结构高度相似？
- [ ] 是否有 AI 生成痕迹（模板化连接词、完美结构、缺乏情感）？
- [ ] 是否加入了足够的新信息（20%+）？
- [ ] 是否改变了叙述视角或文章结构？
- [ ] 是否包含违禁词/敏感词/诱导分享词？
- [ ] 整体是否像是一个真人写的原创文章？

## 四、改写深度等级

根据用户需求，有 4 个改写强度可选（默认使用等级3，除非用户另有说明）：

### 等级1：轻度润色
- 修正语病和表达
- 调整部分同义词
- 保留原结构和大部分内容
- ⚠️ 风险：仅适用于个人素材整理，不可用于发布

### 等级2：中等改写（抄袭擦边）
- 改变段落顺序和开头结尾
- 替换部分案例和表述
- 保留核心论点和约60%内容
- ⚠️ 风险：仍易被判定为洗稿

### 等级3：深度重写（推荐）
- 完全打散原结构
- 改变叙述视角
- 替换50%以上的案例和论据
- 加入个人观点和新信息
- 字数增减 30%-50%
- ✅ 安全：可发表

### 等级4：融合创作（最安全）
- 消化多篇文章的素材
- 提炼新的核心观点
- 原创度 > 85%
- 增加大量新案例、新数据
- 形成独立的写作风格
- ✅✅ 非常安全：高质量原创

## 五、文章类型专项指南

不同类型的公众号文章有不同的改写策略：

### 5.1 观点评论类
- **核心**：观点是灵魂
- **策略**：可以赞同但换角度论证，或提出不同观点
- **确保**：补充新论据，改变论证逻辑链

### 5.2 故事叙事类
- **核心**：情节和情感
- **策略**：改变讲述视角（如从旁观者变成当事人）
- **确保**：细节描述重新组织，情感表达用你自己的方式

### 5.3 干货知识类
- **核心**：信息和逻辑
- **策略**：重新整理知识框架，增加你的理解
- **确保**：用不同的方式解释概念，增加个人实践经验

### 5.4 热点资讯类
- **核心**：时效性和独到解读
- **策略**：快速跟进，但加入独家观点或深度分析
- **确保**：不只是复述事实，要有价值判断和前瞻

### 5.5 情感心理类
- **核心**：共鸣和代入感
- **策略**：用自己的故事或周围人的案例替换
- **确保**：情感表达真实自然，不要照搬原文情绪曲线

### 5.6 测评推荐类
- **核心**：真实体验和客观评价
- **策略**：如果是你没有体验过的产品，必须说明信息来源
- **确保**：加入对比维度、价格分析、适用人群建议

## 七、常见违规场景与应对

| 违规场景 | 风险等级 | 应对方法 |
|---------|---------|---------|
| 段落结构高度相似 | ⚠️高 | 打散重组，改变逻辑顺序 |
| 连续相同表述 | ⚠️高 | 完全重写该段落 |
| 同义词替换痕迹明显 | ⚠️高 | 重新组织句子结构 |
| AI模板化语言 | ⚠️中 | 删除万能连接词，改为自然过渡 |
| 缺乏信息增量 | ⚠️中 | 增加新案例、新观点、新数据 |
| 情感表达平淡 | ⚠️中 | 加入个人感受、反问、感叹 |
| 过于客观中立 | ⚠️中 | 适当加入主观判断和态度 |

## 八、温馨提示

1. **AI是工具，不是作者**：AIWriteX 的一大理念是「AI辅助而非AI生成、人机混合协作」。改写完成后建议用户再人工检查一遍，加入自己独特的表达和感受。
2. **多重参考更安全**：如果能提供 2-3 篇同一话题的文章，融合创作效果远好于单篇改写。
3. **持续学习风格**：注意观察用户公众号的历史文章风格，逐步形成稳定的风格模型。
4. **长期运营策略**：偶尔发布纯原创内容（不是改写来的），提高账号的整体原创信任度。
5. **合规第一**：任何时候如有疑虑，宁可保守也不要冒险。账号被封的代价远大于一篇10w+的收益。
