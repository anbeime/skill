# 故事线纪实爆款短视频拍摄台本生成器

## 📌 概述

本 Skill 用于把**一个真实发生的服务事件**，转化成**可直接上机器拍摄的完整台本**。核心哲学：**真实记录，禁止摆拍**。视频呈现的不是表演，而是真实发生的服务过程——真实感就是这类视频的生命线，一摆拍就变广告，流量就死。

适用于：汽车维修保养、上门服务、售后救援、到店体验等服务类行业的抖音爆款短视频。

## 🎯 适用场景（触发条件）

| 场景 | 触发词 | 说明 |
|------|--------|------|
| **故事线脚本** | "故事线"、"拍一个完整过程"、"上门服务"、"接单到交车" | 用户描述真实服务事件，要求按故事线拍视频 |
| **纪实拍摄台本** | "拍摄台本"、"分镜脚本"、"能直接拍的"、"执行脚本" | 用户要的是可执行台本，不是文案赏析 |
| **服务案例视频** | "客户案例"、"真实客户"、"售后故事" | 用真实客户故事做内容 |
| **系列内容规划** | "做一个系列"、"下期拍什么"、"痛点模板" | 把同一套流程复用到不同故障/服务场景 |

**与其他 Skill 的关系**：爆款文案分析与拆解走 `viral-short-video-script-analyst`；本 Skill 只负责**故事线纪实拍摄台本**的生成与复用。

## 📥 输入处理流程

### Step 1: 采集事件要素

用户描述事件后，先提取以下要素（缺的主动询问）：

| 要素 | 说明 | 示例 |
|------|------|------|
| **客户场景** | 谁、在哪、什么车 | 张先生、钓鱼路上、雷克萨斯 |
| **核心痛点** | 客户遇到的具体问题 | 空调不制冷 |
| **服务动作** | 我们做了什么 | 上门→检测→维修→交车 |
| **技术细节** | 维修的真实过程/根因 | 管路漏冷媒，非压缩机损坏 |
| **公司背书** | 可用的信任素材 | 成立25年、品牌日活动、质保承诺 |
| **转化抓手** | 优惠活动/电话/地址 | 本月活动工时优惠 |

### Step 2: 确认拍摄边界

- 明确出镜人员（服务专员/师傅/客户）
- 明确可拍摄地点（店内/上门/车间）
- 明确是否已与客户沟通拍摄授权
- 明确总时长目标（默认55-65秒）

### Step 3: 输出完整台本

按下方"台本格式规范"输出：11场结构 + 每场6要素 + 台词参考 + 拍摄纪律。

## 🏗️ 故事线爆款方法论

### 三要素（每条视频必须全部体现）

| 要素 | 作用 | 落点 |
|------|------|------|
| **痛点** | 开头制造共鸣，留住观众 | 客户真实讲述，现场收音 |
| **技术** | 中段展示专业，建立信任 | 检测定位、维修过程、前后对比 |
| **服务** | 全程体现态度，促成转化 | 上门、洗车、签字、清单透明 |

### 11步标准故事线流程

```
1 接电话/接单    → 钩子：事件启动，观众好奇
2 准备出发       → 节奏：快速推进，不拖沓
3 上门见客户     → 真实感：现场交流
4 客户讲痛点     → 共鸣：全片情绪核心，现场收音
5 公司背书       → 信任：25年/资质/活动优惠
6 返厂           → 转场：进入专业主场
7 技术维修记录   → 专业：检测-定位-修复全记录
8 修复前后对比   → 反转：数据说话（温度/故障码/异响）
9 交车服务       → 加分：洗车美容等增值服务
10 签字/握手     → 认可：客户满意闭环
11 清单报价+尾板 → 透明：清单明示+联系方式
```

### 钩子设计原则

- 第1场（接电话）或第4场（痛点）画面必须出现在**前3秒**，二选一作开场
- 开场选择依据：痛点更扎心选痛点开场（倒叙），事件更离奇选接单开场（顺叙）
- 前3秒必须让用户停下来，否则完播率崩，算法直接停推

## 📐 台本格式规范

### 每场台本必须包含的 6 要素

| 字段 | 要求 |
|------|------|
| **景别** | 全景/中景/近景/特写，明确标注 |
| **画面** | 具体画面内容，可执行 |
| **动作** | 人物真实动作描述 |
| **台词** | 参考话术（【】内为可替换项），**强调用当事人原话** |
| **字幕/花字** | 只标关键信息点，不遮脸 |
| **机位** | 明确机位设置（固定/跟拍/正反打/多机位） |

### 台本示例骨架（场景一）

```
### 场景一：接电话（0-5s）
| 景别 | 中景→特写 |
| 画面 | 车间/办公室，电话响，专员接起 |
| 动作 | 专员接电话，快速记录，挂断 |
| 台词 | 专员："【车型】空调不制冷？好，我们上门看。" |
| 字幕 | 【花字】"接到电话：【故障描述】" |
| 机位 | 固定机位拍电话，切特写拍记事本 |
```

### 台词编写规范

1. **精炼**：一句一个信息点，杜绝口水话
2. **真实**：台词是"参考话术"，拍摄时让当事人用自己的话讲
3. **技术可信**：专业术语要准确（如"管路漏冷媒，系统缺压"，不能说"空调坏了"）
4. **可替换**：人物、车型、故障、活动信息用【】占位，拍摄前替换
5. **结尾透明**：最后一场必有"查了什么、换了什么、花了多少，一张单子写明白"

## 🔧 常见痛点台词替换包

同一套11步流程，换痛点即可复制下一期。以下为参考话术，按真实情况替换：

### 空调不制冷
- 客户："大夏天这空调吹的全是热风，一路热到目的地，人遭罪。"
- 师傅："问题定位：管路漏冷媒，系统缺压。光加冷媒治标不治本，得查漏补漏。"
- 对比："出风口温度，修前30多度，修完8度，凉了。"

### 底盘异响
- 客户："一过减速带就'咯噔咯噔'响，都不敢开快了。"
- 师傅："摆臂胶套老化开裂，不换的话轮胎偏磨、方向跑偏。"
- 对比："修完上举升机检查，底盘紧凑，过减速带没声音了。"

### 漏油
- 客户："停车一晚上，地上就一滩油，心里发慌。"
- 师傅："【部件】密封老化渗油，光擦干净没用，得换密封件。"
- 对比："修完放一晚上，第二天地面干干净净，不漏了。"

### 烧机油
- 客户："后备箱常年备着机油，三千公里就得加一升。"
- 师傅："【根因：气门油封/活塞环等】，先检测确认再定方案。"
- 对比："跑了一千公里再测，机油尺液位没动。"

### 上门救援/搭电
- 客户："早上起来车打不着火，急死了。"
- 专员："一个电话，我们上门，先检测再处理，不瞎换件。"
- 对比："检测确认是【电瓶亏电/启动机故障】，处理好，一把着车。"

## 🎬 拍摄纪律（硬性要求）

1. **纪实跟拍**：现场发生什么拍什么，禁止摆拍、禁止补演、禁止让客户"演一遍"
2. **收音优先**：全程收环境音+人声，画面可以糙，声音必须真
3. **真实细节**：检测仪数据、温度计读数、里程表、故障码都要拍实
4. **客户授权**：拍摄前必须与客户沟通清楚，尊重客户意愿
5. **多机位**：人一台机、车一台机，素材够剪辑才有余地
6. **可替换信息用【】**：拍摄当天按实际替换，不改结构

## 📋 拍摄前准备清单

| 类别 | 物品 |
|------|------|
| 设备 | 手机×2（人/车各一）、稳定器、补光灯（室内）、备用电池 |
| 道具 | 检测仪、温度计/测距仪（对比实测用）、检修记录单、报价单 |
| 人员 | 服务专员、师傅、客户（提前沟通拍摄授权） |
| 场地 | 客户位置、车间工位、休息区 |

## 🎞️ 后期要点

1. 音乐垫底、音量压低，突出真实对话与环境音
2. 全程上字幕，花字只标关键信息点（痛点、数据对比、背书、联系方式）
3. 总时长55-65秒，前3秒快剪不拖
4. 封面用痛点画面那一帧，配大字标题

## 🚀 流量运营配合要点

| 问题 | 结论 | 动作 |
|------|------|------|
| 蓝V是否限流 | 不会，蓝V反而有流量权益 | 不纠结认证，专注内容 |
| 播放卡几百 | 标签混乱/完播率低/内容像硬广 | 账号垂直化+前3秒钩子+真实记录 |
| 本地流量 | 汽服是本地生意，几百精准播放有价值 | POI精确到商圈/地标，引导同城互动 |
| 冷启动 | 初始流量池300-500播放 | 发布后30分钟黄金期人工推动初始数据 |
| 系列化 | 11步流程可无限复用 | 周更一期，换痛点=新一期 |
