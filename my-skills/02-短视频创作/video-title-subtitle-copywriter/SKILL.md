# 汽修短视频标题·副标题生成器

## 📌 概述

本 Skill 解决一件具体的事：**视频剪完了，标题/副标题憋不出来**。

用户只需要用一句话说清"这条视频讲了什么车、做了什么事、有什么亮点"，本 Skill 就产出**可以直接复制粘贴使用**的全套文案：主标题、副标题、#话题标签、封面大字、以及同事转发视频号时用的推荐语。

核心原则：
- **给成品，不给思路**：直接给多组可直接用的文案，不做长篇分析
- **贴合真实内容**：标题必须能被视频内容兑现，禁止标题党到货不对板
- **合规可长期用**：规避广告法绝对化用语，门店账号不会被限流

## 🎯 适用场景（触发条件）

| 场景 | 触发词 | 说明 |
|------|--------|------|
| **剪完写标题** | "起个标题"、"写个标题"、"这条视频标题怎么写" | 最主流的用法，输入视频内容→输出全套文案 |
| **要副标题/文案** | "副标题"、"文案"、"视频号描述"、"发布文案" | 要一句话补充说明或情绪钩子 |
| **要话题标签** | "标签"、"话题"、"#号怎么加" | 要一组可直接用的 #标签 |
| **同事转发用** | "转发文案"、"推荐语"、"发群里怎么说" | 同事转发视频号/朋友圈时填的一句话 |
| **一次多条备选** | "多给几个"、"来10条"、"换一批" | 批量产出备选，挑一条用 |

**与其他 Skill 的关系**：拍摄环节走 `storyline-video-shooting-script`；直播环节走 `aftersales-live-script`；本 Skill 只负责**发布环节的标题/副标题/标签文案**。

## 📥 输入与追问规则

### 最少输入（只要这三样就能出活）

| 要素 | 说明 | 示例 |
|------|------|------|
| **车型** | 品牌+车系+代号/年份 | 宝马3系 E90 |
| **服务项目** | 做了什么 | 底盘整备 |
| **亮点/钩子** | 最值得说的一件事实 | 换了摆臂胶套，过减速带不响了 |

### 追问规则（缺什么问什么，一次问完，别挤牙膏）

- 缺**车型** → 必问，车型词是汽修标题的流量核心
- 缺**项目** → 必问
- 缺**亮点** → 若无，则改问"车主最在意的是什么 / 修前最难受的表现是什么"
- 缺**平台** → 默认按"视频号为主，兼容抖音"输出，并说明该默认
- 有**脚本/台本** → 直接从台本里提炼车型、故障、技术点、对比数据，不再追问
- **信息实在很少** → 先出稿，同时列出"补上这2条信息能让标题更准"的提示

### 元信息补全（能拿到就带上，标题更具体）

年份、里程数（如 12万公里）、车主身份（如 钓友/跑滴滴的）、地域（如 佛山）、维修耗时/花费、可对比的真实数据（温度、异响消失、故障码清除）。

## 🧠 标题方法论

### 标题四要素

```
[服务项目/症状] + [车型+代号] + [情怀标签 or 痛点共鸣] + [互动引导]
```

用户给的标杆样例即是这个结构：

```
底盘整备  宝马3系E90  当年的操控之王，有遇到同样情况的可以交流  #汽修#底盘整备#宝马#底盘异响
 项目        车型           情怀钩子 + 互动引导                        标签
```

### 六大标题公式（汽修专用）

| 公式 | 结构 | 示例 |
|------|------|------|
| **1. 情怀致敬式** | 车型代号 + 情怀标签 + 互动 | 宝马3系E90 当年的操控之王，有遇到同样情况的可以交流 |
| **2. 痛点提问式** | 车型 + 症状 + 疑问 | 宝马E90底盘松散异响，是不是胶套老化了？ |
| **3. 数字清单式** | 里程/车龄 + N项 + 项目 | 12万公里的E90，底盘整备必换这几样 |
| **4. 前后对比式** | 修前症状 → 修后结果 | 过减速带"咯噔"响，整备完安静得像换台车 |
| **5. 反常识科普式** | 别急着 + 错误做法 + 正确做法 | 底盘异响别急着换减震，先查这三个地方 |
| **6. 纪实剧情式** | 客户场景 + 我们做了什么 | 车主开200公里来找我，只为解决这个底盘异响 |

**公式选用建议**：情怀老车（E90、E46、老捷达、马6）优先用 1；故障类优先用 2、5；整备/大保养优先用 3；有明确修复数据的优先用 4；有真实客户故事的优先用 6。

### 副标题写法

副标题是主标题下面那一行，作用是**补一句"为什么值得看"或延续情绪**。要求：**≤20字，口语，不重复主标题**。

可用的副标题方向：
- 共鸣型：`同款车主进来说说`、`你家车有没有这毛病`
- 悬念型：`问题其实出在这`、`真相和你想的不一样`
- 价值型：`一次讲清底盘整备到底做什么`
- 信任型：`25年老店，只修该修的`
- 引导型：`评论区扣车型，帮你看看`

### 话题标签组合规则

```
品牌词 + 车型词 + 项目词 + 故障词 + （地域词/情绪词，任选其一）
```

- 数量：**3-6 个**为宜，宁精勿多（堆标签反而降权）
- 顺序：把最想被搜到的放前面
- 不要与标题文字**完全重复超过2个词**
- 组合示例：`#汽修 #底盘整备 #宝马 #底盘异响` / `#汽车维修 #宝马E90 #底盘整备 #老车翻新`

## 📱 分平台规范

| 平台 | 标题长度建议 | 风格 | 标签数 | 特别注意 |
|------|--------------|------|--------|----------|
| **视频号** | 15-25字 | 口语、有话题感、带情怀 | 3-5 | **转发推荐语必备**，这是同事转发时填的那句话 |
| **抖音** | 10-20字 | 钩子强、疑问句、同城感 | 3-6 | 加 `#城市名` 抢同城流量 |
| **小红书** | 18-25字 | 痛点前置、可带1-2个emoji | 5-8 | 埋长尾关键词，利于搜索 |
| **朋友圈/公众号** | 20-30字 | 稍正式、带门店信任背书 | 0-2 | 强调到店引导与联系方式 |

> 上表字数为实战经验建议值，非平台官方硬性限制；核心是**把关键信息放在前15字**，超出部分会被折叠。

| 车型 | 常被提到的标签 | 备注 |
|------|----------------|------|
| 宝马 E90 / E46 | 当年的操控之王、后驱直六、驾驶者之车 | 情怀向，需与车主认知一致 |
| 大众 高尔夫GTI / 高R | 小钢炮、平民性能车 | — |
| 马自达 6 / 昂克赛拉 | 东瀛宝马、弯道之王 | — |
| 本田 思域 / 飞度 | 平民超跑、GK5神车 | — |

> 以上均为车圈通行说法，**以实际车况和车主自己的认知为准**，车主不认这个标签就不要用，避免"尬吹"。

### 高频故障/项目词（标签与标题通用）

| 类别 | 词 |
|------|-----|
| 项目 | 底盘整备、四轮定位、大保养、变速箱油、正时、烧机油治理、老车翻新、隔音、改色 |
| 故障 | 底盘异响、漏油、抖动、跑偏、ABS报警、发动机故障灯、变速箱顿挫、空调不制冷 |
| 部件 | 摆臂胶套、减震器、球头、机脚胶、水泵、点火线圈、火花塞 |

### 情绪与互动钩子词

`还有救吗` `值不值` `别急着换车` `老车不弃` `同款车主进` `评论区扣车型` `有遇到同样情况的可以交流` `懂车的都懂`

## 📤 输出格式

每次默认输出以下 5 块（用户只要一部分时，只给那部分）：

```
【主标题备选】5条（标注所用公式，方便挑）
【副标题备选】4条
【话题标签】2-3组可直接用的组合
【封面大字】1条（≤10字的大字标题）
【转发推荐语】1-2条（同事转发视频号/朋友圈可直接复制）
```

输入：`底盘整备，宝马3系E90，换了摆臂胶套，车主说过减速带不响了`

```
【主标题备选】

2. 宝马E90底盘松散发飘，整备完又找回当年的紧致感               （前后对比式）
3. 12年的E90，底盘整备到底该换哪些件？一次说明白               （数字清单式）
4. 过减速带"咯噔"响，问题多半出在这几个胶套上                   （反常识科普式）
5. 车主开200公里来找我，就为解决这个底盘异响                    （纪实剧情式）

【副标题备选】
- 同款E90车主进来聊聊
- 你家车过减速带响不响
- 老车不弃，修好再战十年

【话题标签】
#汽修 #底盘整备 #宝马 #底盘异响
#宝马E90 #汽车维修 #老车翻新 #底盘整备
```

## ⚖️ 合规红线

| 禁止 | 原因 | 替代表达 |
|------|------|----------|
| 最、第一、唯一、顶级、国家级、彻底根治、永久解决 | 广告法绝对化用语，门店账号易被限流/处罚 | 更、很、相当、明显改善、基本解决 |
| 承诺"修完必好""保证不再响" | 维修结果不可绝对承诺 | "实测下来不响了""多数情况能解决" |
| 贬低同行、贬低其他品牌 | 违规且招黑 | 只讲自己怎么做的 |
| 使用客户车牌、人脸、隐私信息 | 侵权 | 打码或改为"某车主""一位E90车主" |
| 虚构未发生的维修数据 | 虚假宣传 | 只用拍到的真实数据 |

> **关于"操控之王"这类词**：这是**对车型的评价**（车圈通行说法），不是对自家服务的绝对化宣传，属于可用的情怀表达；但**不能**写成"本地最专业的底盘整备"。区分点：夸车可以，夸自己别用绝对化词。

## 🔍 自检清单

- [ ] 标题是否包含车型？车型词是否在前15字？
- [ ] 标题是否与视频真实内容对得上？有没有标题党？
- [ ] 是否给了多条备选，并标注了所用公式？
- [ ] 副标题是否≤20字、不重复主标题？
- [ ] 标签是否3-6个、包含品牌+项目+故障词？
- [ ] 是否按平台调整了风格与字数？
- [ ] 是否规避了绝对化用语？
- [ ] 转发推荐语是否单独给了（同事转发要用）？
- [ ] 客户隐私信息是否已脱敏？
