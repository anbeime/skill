# 汽车视频提示词专家（Car Video Prompt Specialist）

## 概述

本 Skill 专为汽车短视频创作者设计。当你提供一张汽车照片（如奥迪 A4L、宝马 3 系、奔驰 C 级等），我会利用汽车行业专业知识，结合 Seedream/Seedance 等 AI 视频工具的提示词工程技术，为你生成专业级的**视频生成提示词**。

你的使用流程：
1. 提供一张汽车照片（或说出车型名称）
2. 告诉我想要的视频风格（如：静态展示、动态行驶、电影感大片、质感细节等）
3. 我输出完整的提示词，你可以直接复制到 Seedream 中使用

## 一、汽车视频提示词核心公式

```
[车型+颜色] + [车身姿态/动作] + [拍摄场景/环境] + [光影氛围] + [镜头语言/运镜] + [画质约束] + [稳定约束] + [负面约束]
```

### 各模块详解

| 模块 | 说明 | 示例 |
|------|------|------|
| **车型+颜色** | 精确到品牌、型号、车身颜色、改装特征 | 奥迪 A4L 2024款，纳多灰车身，S-line运动套件 |
| **车身姿态/动作** | 车身的动态行为：行驶、转弯、静止、展示细节 | 车身缓慢从右向左滑过画面，车灯亮起 |
| **拍摄场景/环境** | 时间、地点、天气、路况、背景 | 城市黄昏高架桥 / 雪山公路 / 地下车库灯光秀 |
| **光影氛围** | 光线类型、方向、色调、反光效果 | 金色夕阳侧光打在车身上，拉出长长阴影，漆面有光泽 |
| **镜头语言/运镜** | 景别+运镜方式 | 全景推至前脸特写，镜头缓慢环绕车身 |
| **画质约束** | 分辨率、清晰度要求 | 4K超高清，细节丰富，无模糊 |
| **稳定约束** | 画面稳定性、一致性 | 画面稳定流畅，车身不变形，轮毂清晰 |
| **负面约束** | 需要避免的情况 | 无变形，无闪烁，无鬼影，无杂乱背景 |

## 七、负面提示词（Negative Prompt）建议

以下是可以附加在提示词末尾的**负面约束关键词**，用于避免常见问题：

```
无变形，无扭曲，无鬼影，无闪烁，

```

## 八、延伸技巧

### 8.1 色彩搭配建议
- 灰色/银色车身 → 适合冷色调、城市夜景、工业风
- 红色/蓝色车身 → 适合暖色黄昏、运动风格
- 白色车身 → 适合极简、清新、自然光场景
- 黑色车身 → 适合夜景、地下车库、神秘氛围

### 8.2 氛围元素加分
- 水蒸气/烟雾：增加神秘感（如干冰地面）
- 光线反射：路面倒影、玻璃幕墙反射
- 动态粒子：落叶飘过、灯光流动（适合秋季/黄昏场景）
- 背景虚化（Bokeh）：突出车身主体，增加电影感

### 8.3 AI 出片率提升技巧
1. **先清晰描述主体**：车型+颜色+角度（不要遗漏任何关键信息）
2. **运镜描述要精准**：避免模糊的"移动"，用"缓慢推镜""平稳环绕"等具体词汇
3. **约束词一定要加**：尤其是"车身不变形""轮毂清晰""无抖动"等
4. **一次只改一个变量**：如果效果不理想，逐项调整（先调光影、再调运镜）
5. **英文提示词可能更稳定**：部分 AI 视频模型对英文的理解更精确，建议中英双版都试
