# 爆款钩子分析器 (Viral Hook Analyzer)

## 概述

本技能专为 **宝驰汇·三禾名车**（邵阳本地同城汽车服务商）定制，提供两大核心能力：

1. **视频钩子分析**：分析用户提供的抖音/短视频（特别是汽车行业/本地同城类视频），识别其使用的爆款钩子类型、结构公式和可复用的核心要素。
2. **爆款文案生成**：基于内置的 200+ 爆款钩子数据库 + 汽车行业专属钩子模板，为宝驰汇·三禾名车生成针对特定车型/服务/本地同城的爆款文案。

---

## 核心背景信息

- **品牌**：宝驰汇·三禾名车
- **行业**：汽车销售服务（新车/二手车/维修保养/汽车服务）
- **地域**：邵阳本地同城
- **目标人群**：邵阳及周边有购车/卖车需求的本地用户
- **核心卖点**：本地老店、信誉保障、车源优质、服务到位
- **出镜人物分工**：写脚本前先确认本次出镜人，**以用户当次指定为准**（用户可能指定 程芳 / 阳阳 / 李玉宝 / 桃子姐（彭总）等）。参考分工：销售/促销类口播常用 **程芳** 或 **阳阳**（两者都做过销售口播人设，勿擅自互相替换）；技术/维修纪实类为 **李玉宝**；老板娘身份为 **桃子姐（彭总）**。若用户未指定，促销口播默认问一句或用占位符【出镜人】。
- **价格表述红线（重要，用户多次强调）**：
  - 视频文案**不固定具体成交价**（不说"落地XX万""XX万就能买"），因为成交价受车源（新车/0km/准新车/二手）、配置、金融方案、置换补贴等多重不确定因素影响，说死价格容易被打脸、引发客诉；
  - 文案中**不得承诺"落地价""0km""准新车"**等受车源影响的不确定表述；
  - 可保留**公开事实**作卖点：官方指导价、配置参数、厂商官方政策（如雷克萨斯四年免费保养）；
  - 价格一律用**弹性承接**："私信我给你算明白 / 底价单直接发你 / 优惠力度直接拉满 / 以实车为准，不搞虚的"。
- **参考爆款形式（视频号"车型+优惠加码"体）**："XX（车型）优惠又加码！来看看有啥优惠…"——出镜人站实车旁口播，30秒内讲完：钩子开头 + 配置亮点快闪 + 弹性价格承接 + 私信导流。无需死价格，贵在真实、简洁、可复制。
- **销售车型口播脚本模板（5段式 · 用户案例提炼，主力生产格式）**：
  ① 钩子 0-5s：价位段 + 车型 + 反差（"四十多万拿下宝马X5""20多万拿下奥迪大7座"）
  ② 人群锁定 5-12s：邵阳老板 / 多人口家庭 / 年轻人，先让人对号入座
  ③ 产品卖点 12-40s：2-3条硬卖点，参数真实（车长/座位布局/动力/屏幕等），不堆砌
  ④ 情感升华 40-48s：把车与身份、家庭、奋斗挂钩，给购买一个"理由"
  ⑤ CTA 48-55s：评论区打车型关键词 + 到店喝茶看车 + 算一份实在报价
  每条另配：视频标题备选×2、话题标签、分镜要点（镜头/画面/字幕）。单条 45-60 秒。
- **价格表述补充**：**可用价位段**（十几万 / 二十多万 / 不到40万 / 四十多万）作钩子锚点（用户案例即如此），但**不报具体成交金额、不承诺"落地XX万"**；CTA 用"到店喝茶看车，给你算一份实在报价/购车方案"承接。
- **销售 IP**：宝驰汇销售口播由 **阳阳** 与 **程芳** 两位出镜（可轮换、可互换代拍）；账号做成矩阵，统一开场手势、结尾口号与封面模板。
- **PPT 设计偏好（重要）**：生成 PPT/HTML 报告时**禁止使用黑色背景**，一律使用浅色/米白背景（如米白 F5F0E6、暖白 F7F5F0、白 FFFFFF），深色只用于文字或局部强调。此为用户明确要求，必须始终遵守。

## 触发条件

**当用户出现以下行为时，必须立即调用本技能：**
- 用户提供抖音/TikTok/短视频链接，要求"分析这个视频的钩子"、"看看这个视频为什么火"、"拆解这个视频"
- 用户要求"写爆款文案"、"写钩子开头"、"写 5 秒留人文案"、"写个爆款视频脚本"
- 用户说"帮我写个视频开头"、"给个钩子模板"、"套用钩子写文案"
- 用户提到各类型爆款钩子关键词
- **特别场景：用户提供汽车/本地同城类视频要求分析，或要求为宝驰汇·三禾名车写汽车类爆款文案**

## 工作流程

### 模式一：视频钩子分析

当用户提供视频链接时，按以下步骤执行：

#### 步骤1：获取视频内容
- 通过 WebFetch 获取视频页面信息（标题、描述、作者、点赞/评论数据）
- 如页面信息不足，通过 WebSearch 搜索该视频相关内容
- **汽车行业视频特别关注**：视频是讲车型介绍的、行业干货的、情感故事的还是客户案例的

#### 步骤2：钩子拆解分析
按照以下框架进行分析，输出结构化分析报告：

```
📹 视频钩子分析报告

【基本信息】
- 视频标题/主题：
- 发布者：
- 数据表现（点赞/评论/分享）：
- 所属赛道：

【钩子类型鉴定】
- 主钩子类型：□ 结果型 □ 痛点型 □ 悬念型 □ 冲突/反常识型 □ 情绪共鸣型
- 具体子类型：
- 匹配模板公式：

【钩子结构拆解】
- 前3秒内容：
- 3-5秒内容：
- 钩子核心逻辑：
- 使用了哪些钩子元素（数字/对比/反问/情绪词/场景等）：

【可复用的要素】
- 可迁移的公式：
- 适合的赛道：
- 为什么有效：

【改编到宝驰汇·三禾名车的建议】
- 如何改成汽车版本：
- 如何融入邵阳本地元素：
- 同类型其他钩子模板：
```

#### 步骤3：提供同类型钩子推荐
基于分析出的钩子类型，从内置钩子数据库中推荐 3-5 个同类钩子模板供用户参考。

---

### 模式二：爆款文案生成

当用户要求写爆款文案时，按以下步骤执行：

#### 步骤1：收集需求

**汽车行业专属需求收集：**

| 维度 | 说明 | 示例 |
|------|------|------|
| 视频类型 | 车型介绍 / 行业干货 / 客户案例 / 人设IP / 活动促销 | 一台准新宝马3系讲解 |
| 目标人群 | 首次购车 / 置换车主 / 预算XX万 / 宝妈 / 年轻人 | 邵阳本地想买10万左右代步车的 |
| 核心卖点 | 价格优势 / 车况保障 / 服务承诺 / 本地口碑 | 三年质保、历史车况透明 |
| 视频时长 | 15秒 / 30秒 / 60秒 | 15-20秒 |
| 风格偏好 | 干货式 / 情感式 / 搞笑 / 反常识 / 硬核 | 干货+真诚 |
| 是否本地同城 | 是否强调邵阳本地元素 | 是 |

#### 步骤2：匹配钩子类型

**汽车行业赛道钩子匹配表：**

| 内容类型 | 推荐钩子类型 | 推荐理由 |
|----------|-------------|---------|
| 车型介绍/评测 | 数字冲击型 / 反差冲击型 | 具体数字+车型对比吸引点击 |
| 行业避坑/干货 | 痛点型 / 警告避坑型 | 戳中"怕被坑"的核心焦虑 |
| 客户案例/成交故事 | 对抗反转型 / 情绪共鸣型 | 真实故事有感染力 |
| 人设IP / 老板出镜 | 结果型 / 身份标签型 | 建立专业信任感 |
| 活动促销/价格 | 数字碾压型 / 稀缺紧迫型 | 价格数字+限时感刺激转化 |
| 同城本地内容 | 地域标签型 / 身份认同型 | "邵阳本地人"拉近距离 |
| 热门车型话题 | 借势型 / 悬念冲突型 | 蹭热度 + 引爆评论 |

#### 步骤3：生成文案结构

完整的爆款短视频文案结构：

1. **钩子开头（前3-5秒）**：从钩子数据库中选择/改编
   - 8-18字口播，3秒读完
   - 屏幕配加粗大字（单行4-8字）
2. **内容主体（10-30秒）**：承接钩子，展开核心内容
3. **结尾转化（最后3-5秒）**：引导互动（评论区打预算/到店看车/关注）

#### 步骤4：输出格式

```
📝 爆款视频文案（宝驰汇·三禾名车定制）

【使用钩子】
类型：XXX型钩子
公式：【公式模板】

【完整脚本】

🎬 前3-5秒（钩子）：
口播：[文案]
画面：[画面描述]
字幕：[屏幕大字]

🎬 主体内容（10-30秒）：
[核心内容 + 画面/字幕建议]

🎬 结尾（3-5秒）：
口播：[互动引导]
画面：[品牌信息露出]

【钩子解析】
▸ 为什么选这个钩子：
▸ 核心痛点/爽点：
▸ 预期完播效果：
```

## 爆款钩子数据库（通用50个）

### 第一类：结果型钩子（10个）

核心逻辑：先把最炸的结果扔出来，用户想知道"怎么做到的"

**1. 时间+结果**
- 公式：用了【时间】，我做到了【具体结果】
- 示例："用了3个月，我还清了20万债务"
- 实操：把你最骄傲的一个成果，加上时间数字

**2. 数字+反差**
- 公式：月薪【低数字】，一年存了【高数字】
- 示例："月薪5000，一年存了5万"
- 实操：收入和存款差距越大越吸引人

**3. 从X到Y**
- 公式：从【差状态】到【好状态】，我只做了这一件事
- 示例："从社恐到销冠，我只改了这一点"

**4. 之前vs之后**
- 公式：以前我【坏结果】，现在我【好结果】
- 示例："以前熬夜到3点睡不着，现在10分钟入睡"

**5. 最低成本+最高回报**
- 公式：只花了【低价】，拿到了【高价值】
- 示例："只花了50块，我把出租屋改成了ins风"

**6. 普通人+不普通结果**
- 公式：我一个【普通人】，是怎么【不普通结果】的
- 示例："我一个普通上班族，是怎么3个月涨粉5万的"

**7. 最短时间+最大变化**
- 公式：【短时间】内，我发生了【大变化】
- 示例："30天内，我的皮肤从烂脸到素颜出门"

**8. 拒绝+结果**
- 公式：我拒绝了【诱惑】，换来了【好结果】
- 示例："我拒绝了月薪3万的offer，现在赚得更多"

**9. 没想到+结果**
- 公式：没想到，【一个简单动作】让我【好结果】
- 示例："没想到，每天早起30分钟，我一年读了50本书"

**10. 被质疑+结果**
- 公式：所有人都说【不可能】，但我【做到了】
- 示例："所有人都说我做不起来，现在我有20万粉"

---

### 第二类：痛点型钩子（10个）

核心逻辑：先戳用户最疼的地方，让他觉得"这说的就是我"

**11. 你是不是也这样**
- 公式：你是不是也【痛点场景】
- 示例："你是不是也这样，每天忙得要死却什么都没干？"

**12. 我懂你**
- 公式：我知道你【痛点】，因为我也是这样
- 示例："我知道你不敢跟领导提加薪，因为我也不敢"

**13. 别再…了**
- 公式：别再【错误做法】了
- 示例："别再熬夜了，真的会猝死"

**14. 多少人+不知道**
- 公式：90%的人都不知道，【真相】
- 示例："90%的人敷面膜都敷错了"

**15. 你有没有过**
- 公式：你有没有过【具体场景】
- 示例："你有没有过，加班到凌晨，地铁停了，打车舍不得？"

**16. 最怕**
- 公式：【人群】最怕的【数字】件事
- 示例："职场新人最怕的3件事"

**17. 为什么你…还是…**
- 公式：为什么你【努力做某事】，还是【坏结果】
- 示例："为什么你每天健身，还是瘦不下来？"

**18. 别等到…才…**
- 公式：别等到【坏结果】，才开始【好行为】
- 示例："别等到牙疼，才想起来刷牙"

**19. 你不是…你是…**
- 公式：你不是【表面问题】，你是【深层问题】
- 示例："你不是懒，你是能量太低了"

**20. 我踩过…你别踩**
- 公式：我踩过【数字】个坑，你别踩了
- 示例："装修我踩过8个坑，你别踩了"

---

### 第三类：悬念型钩子（10个）

核心逻辑：说一半藏一半，让用户"抓心挠肝"想知道答案

**21. 我发现了…的秘密**
- 公式：我发现了【领域】的一个秘密
- 示例："我发现了小红书涨粉的一个秘密"

**22. 千万不要…**
- 公式：千万不要【常见行为】，尤其是【人群】
- 示例："千万不要在晚上做决定，尤其是敏感的人"

**23. 我只做了…但结果…**
- 公式：我只做了【简单动作】，但结果【出乎意料】
- 示例："我只改了标题的一个字，播放量翻了10倍"

**24. 如果…就会…**
- 公式：如果你【不做某事】，就会【坏结果】
- 示例："如果你还在用这种方式存钱，你会越存越穷"

**25. 那天我做了一个决定**
- 公式：那天我做了个决定，然后一切都变了
- 示例："那天我裸辞了，然后一切都变了"

**26. 我不敢相信…**
- 公式：我不敢相信，【意外结果】竟然发生了
- 示例："我不敢相信，一个月的改变这么大"

**27. 这就是为什么…**
- 公式：这就是为什么【现象】会发生
- 示例："这就是为什么你越努力越穷"

**28. 我花了X年才明白**
- 公式：我花了【时间】，才明白【道理】
- 示例："我花了3年，才明白工作不是越努力越好"

**29. 一句话说透**
- 公式：一句话说透【复杂问题】
- 示例："一句话说透怎么跟领导提加薪"

**30. 听劝…**
- 公式：听劝，【一个建议】
- 示例："听劝，别在简历上写'熟练使用Office'"

---

### 第四类：冲突/反常识型钩子（10个）

核心逻辑：制造反差、矛盾、颠覆，让用户"哎？"一下

**31. 越…越…**
- 公式：越【A】，越【反常识的B】
- 示例："越努力，越贫穷"

**32. 别再信…了**
- 公式：别再信【普遍认知】了
- 示例："别再信'早起改变人生'了"

**33. 谁说…就要…**
- 公式：谁说【A】就要【B】
- 示例："谁说30岁就要结婚？"

**34. 我劝你…**
- 公式：我劝你【反常识建议】
- 示例："我劝你别和同事做朋友"

**35. 真正的X不是Y**
- 公式：真正的【A】，不是【B】，是【C】
- 示例："真正的自律，不是早起，是不想做的事也能做"

**36. X分钟 vs X小时**
- 公式：【短时间】搞定【别人长时间】的事
- 示例："10分钟搞定别人3小时的PPT"

**37. 废掉一个人最好的方式**
- 公式：废掉一个人最好的方式，是【行为】
- 示例："废掉一个人最好的方式，是让他忙到没时间成长"

**38. X和Y，差的不是Z**
- 公式：【A】和【B】的差距，不是【表面】，是【本质】
- 示例："你和学霸的差距，不是智商，是方法"

**39. 我不…但…**
- 公式：我不【常规优点】，但我【做到了】
- 示例："我不是名校毕业，但我进了大厂"

**40. 你以为…其实…**
- 公式：你以为【错误认知】，其实【真相】
- 示例："你以为存钱是靠省，其实靠赚"

---

### 第五类：情绪共鸣型钩子（10个）

核心逻辑：先让用户"有感觉"，再让他"听你说"

**41. 只有X才懂**
- 公式：只有【人群】才懂，【感受】
- 示例："只有职场妈妈才懂，下班回家还要'上晚班'的感觉"

**42. 那一刻我破防了**
- 公式：那一刻我破防了，因为【事件】
- 示例："看到我妈的白头发，那一刻我破防了"

**43. 说实话…**
- 公式：说实话，【真实想法】
- 示例："说实话，我不想结婚"

**44. 如果你也…抱抱你**
- 公式：如果你也【经历】，抱抱你

### 板块三：汽车短视频实操8条铁律

1. **字数卡死标准**：口播钩子控制在8-18字，3秒读完，超22字必拖节奏被划走；屏幕大字标题单行4-8个字
2. **必加数字**：数字=具象收益/损失，用户敏感度翻倍。公式：数字 + 亏钱/省钱/踩坑。例："忽略1个细节，买车亏6000"
3. **精准锁定人群**：开头带上"邵阳""本地""准备买车""代步"等关键词，精准抓目标客户
4. **制造矛盾反差**：价格反差（同款车差1.6万）、表里反差（外观精品实为事故车）、认知反差（老司机不全款买车）
5. **巧用负面痛点**：多用"被骗、亏、踩坑、套路、大修、白花钱"，少用"省钱、利好"
6. **悬念留白不说答案**：钩子只抛问题不抛答案。❌"3招辨别泡水车" ✅"泡水车藏3个破绽，内行从不外露"
7. **画面+字幕配合**：前3秒全屏加粗大字，黄字黑底/红字白底，画面和文案同步
8. **稀缺紧迫感留人**：关键词"圈内机密、快要下架、很少人知道、抓紧收藏"
