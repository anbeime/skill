# 汽车品牌主题海报 · Seedance 生图提示词生成器

把「主题 + 车型 + 颜色 + 场景」组合成一段可直接粘贴到 Seedance（或任何文生图/图生图模型）的完整提示词，并附参数块、禁止项和自检清单。

## 何时调用

用户提到以下任意一种情况时调用本 skill：

- 要「汽车海报提示词 / 生图提示词 / 生图 prompt」
- 要「早安 / 午安 / 晚安 / 雨夜 / 商务 / 节气」系列海报
- 要「换个车型 / 换个颜色 / 换个场景 / 换句文案」重出一版
- 要「海报风格库 / 加一种风格 / 场景怎么定义」
- 要给某个车型、节日、节气、门店活动做竖版海报

## 使用方式

### 最小输入（缺什么用什么默认值）

| 槽位 | 说明 | 默认值 |
|---|---|---|
| 主题 | 早安/午安/晚安/雨夜/商务/节气 | 晚安 |
| 车型 | 见车型库 | 豪华行政级轿车 |
| 车身颜色 | 见车漆库 | 深酒红色金属漆 |
| 风格编号 | 见风格库 1-12；不指定则按主题自动匹配 | 晚安→风格1 |
| 每日文案 | 8-14 字中文短句 | 由主题生成 |
| 比例 | 竖版 | 9:16 |

### 输出结构（严格按此 7 段，方便直接粘贴）

```
【第1段 主指令】制作一张<品牌调性>的<主题>主题竖版海报，9:16构图。
【第2段 场景】时间/天气/主体建筑或环境/对称性/灯光/冷暖对比。
【第3段 车辆】车型/视角/朝向/比例/车漆颜色/高光/轮毂/反射/落地阴影。
【第4段 构图】机位高度/主体居中/车辆占宽比例/前景/上方与下方留白区。
【第5段 风格】摄影风格/美学/配色/材质/光影/清晰度关键词。
【第6段 禁令】只生成场景和汽车，不生成任何文字、Logo、水印、二维码或虚假车标。
【第7段 参数块】【主题】【汽车款式】【车身颜色】【场景】【时间】【天气】【主色】【灯光】【情绪】【每日文案】
```

之后再附「禁止项」全量清单与「参考图规则」。

- **1-3 东方建筑系**：必须写「建筑沿画面中轴严格对称」「飞檐/白墙/深色木结构」「庭院松树与灌木修剪整齐」

- **6-9 节气系**：必须写清当季植物（桂花/银杏/积雪/青瓦雨痕）与空气质感

- **12 公路系**：必须写「路面标线清晰」「远景层峦云海」「车头朝画面深处或左侧统一」

## 车型库

豪华行政级轿车 / 中大型豪华SUV / 大型豪华MPV / 纯电轿跑 / 硬派越野车 / 城市紧凑型SUV / 高性能跑车 / 豪华皮卡

写车型时统一加一句：`车辆呈完整标准<视角>视角，车头朝左，车身水平，比例修长稳重。`

视角可选：标准侧面 / 前45度 / 前脸正对 / 后45度。**同一系列海报必须用同一视角**，保证整套视觉统一。

## 车漆库

车漆固定搭配句：`车身颜色为<车漆>，车顶与车窗带银灰色高光，大尺寸精致多辐轮毂，车漆反射周围环境光。`

## 快速替换操作

换任何东西都只改对应槽位，**不要改动 7 段结构**：

| 需求 | 只需改 |
|---|---|
| 换车型 | 【汽车款式】+ 第3段车型词 |
| 换颜色 | 【车身颜色】+ 第3段「车身颜色为…」 |
| 换季节/节气 | 风格编号 +【场景】【时间】【天气】【主色】【灯光】+ 第2段 |
| 换文案 | 【每日文案】（8-14 字，对仗或短句） |
| 换比例 | 主指令的「9:16」，横版改 16:9、方版改 1:1 |
| 整套系列 | 固定车型+视角+车漆，只换主题与场景 |

## 禁止项（每次输出都要带上，可整段复制）

不要文字，不要乱码，不要Logo，不要二维码，不要水印，不要错误车标，不要多余车辆，不要人物，不要车门打开，不要车辆变形，不要车身过短或过长，不要轮胎椭圆，不要轮毂错位，不要车轮数量错误，不要悬浮，不要透视错误，不要建筑歪斜，不要左右结构不对称，不要过曝灯光，不要廉价霓虹效果，不要卡通感，不要插画感，不要塑料材质，不要AI纹理，不要低清晰度，不要画面中出现真实车牌文字。

## 参考图规则（有真实产品车图时必须写）

> 车辆必须严格保持参考图中的车型结构、前脸、车灯、车窗、门把手、腰线、轮毂、车标和车身比例，只允许调整车漆颜色、环境反光和场景光影。

使用真实车图作参考时，把这条原文附在提示词最后，不要改写。

## 生成后自检清单（逐条对，不合格就重出）

1. 车辆真实落地，轮胎与地面有自然接触阴影，不悬浮
2. 车头朝向统一（默认朝左），车身水平
3. 车轮数量 4 个，无椭圆、无轮毂错位、无变形
4. 建筑沿中轴严格对称，不歪斜
5. 冷暖对比成立，无局部过曝、无廉价霓虹
6. 画面中无文字、无 Logo、无水印、无二维码、无错误车标
7. 无人物、无多余车辆、无车门开启
8. 9:16 竖版，车辆横向占画面约 85% 宽
9. 上方保留 Logo 与主题文字区域，下方保留日期、心语与二维码区域
10. 材质真实（金属漆反射、玻璃通透、石材纹理），无塑料感、无 AI 涂抹感
11. 参考图车型结构未被改动（仅颜色与光影变化）
12. 同一系列多张图之间，车型、视角、机位、配色保持一致

## 与 PS 后期衔接

生成图**只出场景和车**，文字/Logo/日期/二维码全部在 PS 后期添加：

- 上方留白区 ≈ 画面高度 18%，下方留白区 ≈ 22%，给后期文字留位置
- 后期加二维码时注意：纯黑画在纯白上、四周留 ≥4 个模块静区、边长 ≥400px、导出 JPEG 质量 ≥90、色彩模式 sRGB，加完先发微信长按实测一次
- 一整套系列（早安/午安/晚安）建议共用同一套文字层级与位置，只换内容
