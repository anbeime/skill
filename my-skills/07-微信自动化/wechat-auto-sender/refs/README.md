# refs —— 参考图目录

这里存放程序用于**防止发错人**的参考截图，由 `--calibrate` 自动生成：

| 文件 | 用途 |
| --- | --- |
| `<备注名>_title.png` | 目标对象聊天**标题区**的截图，发送前用来比对，确认打开的确实是目标对象 |
| `输入框空参考图.png` | 聊天**输入框为空**时的截图，发送前用来确认没有残留草稿 |

## 为什么这些图不入库

参考图里包含聊天标题（对方昵称/群名）等个人信息，因此 `.gitignore` 已排除 `refs/*.png`。

生成方式：

```powershell
python scripts\send_daily.py --calibrate "示例群聊"
```

生成后请**人工看一眼**，确认标题与聊天内容确实是你要发送的对象，再投入使用。
