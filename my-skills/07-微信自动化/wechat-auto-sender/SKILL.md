# 微信定时自动发送图片（wechat-auto-sender）

一个跑在 Windows 上的微信「定时发图」机器人：每天到点自动打开已登录的微信，
把指定日期的图片发给指定的人或群，发完自动恢复窗口，全程无人值守。

设计取向是**宁可失败，绝不误发**——所有关键动作前都有校验闸门，任何异常都会先中止并留下现场证据。

---

## 一、什么时候用它

只要用户出现下面这类诉求，就调用本技能：

- 「每天凌晨自动把早安图/晚安图发到群里」
- 「微信定时群发图片」「微信自动发消息」
- 「把某个联系人/群加入自动发送名单」
- 「昨天/今天该发的图没发出去，帮我查原因」
- 「给微信自动发送程序加一个发送对象 / 换图片目录 / 改发送时间」

## 二、能力清单

| 能力 | 说明 |
| --- | --- |
| 定时发送 | 配合 Windows 任务计划，每天定点无人值守运行 |
| 多目标 | 一次运行按配置顺序发多个联系人或群聊 |
| 多类别 | 每天可发多张（如「早安」「晚安」），按文件名规则匹配当天图片 |
| 防错发 | 打开聊天后比对**标题参考图**，不匹配就换下一行重试，绝不乱发 |
| 防残稿 | 发送前校验输入框是否为空，避免把上次残留草稿一起发出去 |
| 防误点 | 鼠标/键盘操作前强制确认前台是微信进程，否则立即中止 |
| 断点续发 | 记录当天发送状态，已发过的不重复发；支持 `--force` 强制重发 |
| 失败取证 | 出错时自动保存窗口截图、全屏截图与窗口信息文本，便于复盘 |
| 演练模式 | `--dry-run` 完整走流程但不点发送，安全验证配置 |
| 试发模式 | `--test` 只发到「文件传输助手」，验证链路 |
| 校准模式 | `--calibrate` 自动生成某对象的标题参考图 |

## 四、快速开始

```powershell
# 1) 安装依赖
pip install -r requirements.txt

# 2) 准备配置：复制模板后按注释逐项修改
Copy-Item config.example.json config.json

# 3) 校准：让程序打开目标聊天并保存标题参考图，人工确认是否是正确对象
python scripts\send_daily.py --calibrate "示例群聊"

# 4) 演练：完整走流程但不发送
python scripts\send_daily.py --dry-run

# 5) 试发：只发到「文件传输助手」
python scripts\send_daily.py --test

# 6) 正式运行
python scripts\send_daily.py
```

确认无误后，用 Windows 任务计划程序调用 `scripts\run_send.cmd` 即可定时无人值守。

## 五、命令行参数

| 参数 | 作用 |
| --- | --- |
| 无参数 | 正式发送（定时任务使用） |
| `--dry-run` | 演练：完整走流程，只粘贴不点发送 |
| `--test` | 试发到「文件传输助手」 |
| `--date 9-18` | 指定发送哪一天的图（格式 `M-D`） |
| `--force` | 忽略「当天已发过」记录，强制重发 |
| `--calibrate "对象"` | 打开该对象的聊天并保存标题参考图 |
| `--calib-method click\|key` | 校准时的打开方式 |

## 六、配置要点（config.json）

| 字段 | 说明 |
| --- | --- |
| `图片文件夹` / `文件名格式` / `发送类别` | 图片从哪来、怎么命名、每天发哪几类 |
| `发送对象[]` | 每个对象含 `备注名`、`搜索关键词`、`标题参考图` |
| `测试对象[]` | `--test` 时使用的对象（建议留「文件传输助手」） |
| `微信程序` / `启动等待秒数` | 微信可执行文件路径与冷启动最长等待 |
| `窗口位置` / `界面坐标` | 运行时把微信移到固定位置，保证点击坐标准确 |
| `验证标题` / `标题相似度阈值` | 标题校验开关与阈值，**不要为了「提高成功率」调低** |
| `日期口径` | `today` 用当天日期，`yesterday` 用前一天 |
| `缺图处理` | `skip` 缺图就跳过；`latest` 用文件夹里最新一套补齐 |
| `同一目标同一天只发一次` | 防止同一天重复打扰 |

> 换电脑或改微信窗口尺寸后，必须重新校准：用 `--calibrate` 生成标题参考图，
> 并按实际界面微调 `界面坐标`。

## 七、安全底线（调用本技能时必须遵守）

1. **不要**把 `config.json`、`refs/*.png`、`logs/`（含聊天截图）提交到公开仓库——里面有联系人与聊天画面。
2. **不要**为了让程序「更容易成功」而调低 `标题相似度阈值` 或关闭 `验证标题`。
3. 运行期间微信窗口会被临时前置，属于正常现象；但**不要**在程序运行时抢占鼠标键盘。
4. 锁屏状态下界面不可交互，程序会直接放弃本次执行（返回码 3），这是预期行为。
5. 群发/定时消息可能触发平台风控，请控制频率，仅用于自己的账号与已授权的对象。

## 八、返回码

| 返回码 | 含义 |
| --- | --- |
| 0 | 执行成功（可能包含「当天已发过，跳过」） |
| 1 | 执行完成但有目标发送失败 |
| 2 | 运行失败（配置错误、微信不可用、前置窗口失败等） |
| 3 | 锁屏导致放弃本次执行 |
