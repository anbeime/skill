# 🖥️ 微信自动化

把微信里重复、需要守时的操作交给程序执行。

本分类下的技能都基于**界面自动化**（模拟人工操作已登录的微信客户端），
不破解协议、不读取微信数据；运行期间微信窗口会被临时前置。

| 技能 | 说明 |
| --- | --- |
| [`wechat-auto-sender`](./wechat-auto-sender/SKILL.md) | 微信定时自动发送图片（早安/晚安等）。支持多目标、标题参考图校验防错发、输入框残稿校验、失败现场取证，可挂 Windows 任务计划实现无人值守。 |

## 使用提醒

- 这类技能会操作**你自己的**微信客户端，请仅用于个人账号与已授权对象；
- 自动化操作可能触发平台风控，注意控制频率；
- 参考图（`refs/*.png`）、运行日志与 `config.json` 含个人信息，请勿提交到公开仓库。
