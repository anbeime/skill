# 微信视频号助手

## 概述

**微信视频号助手** 是一个专注于微信视频号（Channels）的数据采集与分析助手。视频号不公开播放量和粉丝数，核心关注指标为：**点赞 / 收藏 / 转发 / 评论**。

助手提供三大核心能力：
1. **搜索发现** — 按话题搜视频、按名字找博主
2. **数据采集** — 单条视频采集、博主全部作品采集、评论采集
3. **分析加工** — 视频数据分析、口播文案改写

## 使用说明

### 一、搜索发现

#### 1. 搜视频（按话题搜索）

**说「搜索[关键词]」**，例如：
- 搜索美食
- 搜索汽车
- 搜索旅行vlog

系统会按相关 **话题** 搜索视频号视频，展示该话题下的爆款内容。

**可选参数：**
- 排序方式（按点赞量/发布时间等）
- 返回条数（可指定数量）

#### 2. 找博主（按名字搜索）

**说「找[博主名称]」**，例如：
- 找央视新闻
- 找人民日报
- 找李子柒

系统会按 **名字** 搜索视频号博主，返回：
- 博主昵称
- 作品数
- 合集数
- 关联公众号
- 博主签名 / 地区

---

### 二、数据采集

#### 1. 单条视频采集

**发给我视频分享链接**，我会自动提取：

| 提取内容 | 说明 |
|---------|------|
| 点赞数 | 该视频的点赞数量 |
| 收藏数 | 该视频的收藏数量 |
| 转发数 | 该视频的转发数量 |
| 评论数 | 该视频的评论数量 |
| 标题 | 视频标题文案 |
| 口播文案 | 视频中的口播文字内容 |
| 封面 | 视频封面图片 |
| 无水印视频 | 去水印的视频文件 |

所有数据自动排版导出为 **Excel 表格**。

#### 2. 博主作品采集

**方式一：** 先「找[博主名称]」找到博主，然后说「拉他全部作品」

**方式二：** 直接发该博主的一条视频链接，系统自动识别博主身份，然后说「拉他全部作品」

**可选参数：**
- 指定条数（如「拉20条作品」）
- 全部作品（说「拉全部作品」）

#### 3. 评论采集

**发给我视频分享链接**，然后说「采集评论」

系统会自动提取：
- 评论内容
- 评论点赞数
- 评论回复

**可选参数：**
- 指定评论条数（如「采集50条评论」）
- 全部评论

---

### 三、博主信息查询

先通过「找[博主名称]」或发一条该博主的视频链接，系统自动识别博主身份后，可查询以下信息：

#### 博主资料
自动返回：昵称 / 签名 / 地区 / 作品数 / 合集数 / 关联公众号

> 注意：视频号平台不公开粉丝数和播放量，所以无法获取这些数据。

#### 博主合集
说「查看合集」或「他的合集列表」，返回该博主的所有合集。

#### 直播回放
说「直播回放」或「他的直播回放」，返回该博主的直播回放列表。

#### 号内搜索
说「在[博主名]里搜[关键词]」，在指定博主的视频内容中按关键词搜索。

---

### 四、分析加工

分析加工功能在 **已提取的数据上** 进行，结果会写回到同一张表格中。

#### 1. 视频分析

**说「分析这条视频」** 或 **「分析这个博主」**

系统会分析：
- **爆点分析**：视频的亮点和吸引人的点
- **结构分析**：视频的内容结构（开头-中间-结尾）
- **套路分析**：使用的视频套路和技巧
- **优化建议**：如何改进

#### 2. 文案改写

**说「把这条视频的口播文案改写一下」**

系统会基于原文改写口播文案，支持多种风格：
- 口语化风格
- 正式风格
- 短视频爆款风格
- 讲故事风格

---

### 五、导出格式

所有采集数据自动导出为 **排版好的 Excel 表格**，包含：

| 工作表 | 内容 |
|-------|------|
| 视频数据 | 标题/点赞/收藏/转发/评论/发布时间 |
| 评论数据 | 评论内容/点赞/回复/用户 |
| 文案分析 | 口播文案/改写版本/分析结果 |
| 博主信息 | 昵称/签名/地区/作品数/合集数 |

## 使用技巧

### 高效工作流

```
场景一：采集热门话题视频
1. 搜索美食            → 搜索话题
2. 采集前10条          → 指定条数采集
3. 分析这条视频        → 分析爆款视频结构

场景二：调研竞品博主
1. 找XX汽车           → 搜索博主
2. 拉他全部作品        → 拉取所有作品
3. 分析这个博主        → 分析博主内容策略

场景三：获取视频素材
1. 分享视频链接        → 发链接给助手
2. 采集评论            → 获取用户反馈
3. 把文案改写一下      → 改写口播文案做参考
```

### 注意事项

1. **搜索 vs 找的区别**
   - **搜索[关键词]** = 搜话题下的视频
   - **找[博主名]** = 按名字找博主

2. **认准博主后再拉作品**
   - 想要某博主全部作品，先「找他名字」确认是他，再说「拉他全部作品」

3. **数据可用性说明**
   - 视频号平台**不公开**播放量和粉丝数
   - 核心数据为：点赞 / 收藏 / 转发 / 评论

4. **分析加工的前提**
   - 视频分析和文案改写需要在已有采集数据的基础上进行
   - 建议先采集视频数据，再进行深度分析

## 常见问题

**Q: 视频号为什么不显示播放量？**
A: 微信视频号平台本身不公开播放量数据，这是平台规则限制。

**Q: 能否采集到粉丝数？**
A: 不能。视频号平台不公开博主粉丝数。

**Q: 采集速度如何？**
A: 取决于视频数量和网络情况，单条视频采集较快，批量采集可能需要一些时间。

**Q: 导出的Excel在哪里？**
A: 采集完成后，Excel文件会保存在工作目录中，可以直接打开查看。

**Q: 支持批量采集多个博主吗？**
A: 支持。可以先搜索博主，然后逐个拉取作品，所有数据会分工作表整理。
