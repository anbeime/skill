## 🚀 使用方式

### 一键全自动
```
"全自动 [任务描述]"
→ 自动拆解 → 匹配团队 → 并行/串行执行 → 汇总交付
```

### 指定团队
```
"让金融投资团分析一下茅台"
"内容创作团帮我写篇文章"
"技术开发团帮我搭个网站"
```

### 多团协作
```
"团队分析 [复杂主题]"
→ 多团队并发出击 → 汇总报告
```

### 一条龙
```
"一条龙 [端到端任务]"
→ 研究 → 创作 → 设计 → 交付
```
