```bash
cd C:\D\zhiyi\antinet-agentteams
python run_agentteams_local.py --topic "SnSe 空位工程导热" --no-reset
```
- 该入口是**自包含 Python 编排器**（零外部依赖，仅标准库），直接装载 7 个官署 Worker，
  按 `PIPELINE` 顺序派发；不依赖 AgentTeams 控制器即可运行，但**已接入真实知易知识库**。

## 四、本地运行路径 B（真 AgentTeams/Hiclaw，复赛 live 演示，需 Docker）

路径 A 证明"八官署 + 知识库"逻辑闭环，但**不是**在 AgentTeams 集群内调度。复赛要求可执行 AgentTeams 代码包 + 真调度演示时，走此路径：

**前提**：Docker 已起（你已完成）+ 安装 AgentTeams(Hiclaw)：
```bash
bash <(curl -sSL https://higress.ai/hiclaw/install.sh)
# 安装器：运行时选 qwenpow；配 LLM Key；端口 18088；E2EE 关
```

**步骤**：
1. 起 manager：`docker` 拉起 hiclaw-manager，访问 `http://127.0.0.1:18088` 的 Element Web。
2. 清 manifest 非法字段（见 `AgentTeams_集成真实度核查.md`）：删 `Manager.config/resources`、`Worker.resources/state`、`Team.heartbeatEvery`——框架 CRD 无这些字段，apply 会被静默裁剪。
3. `agentteams apply -f manifests/manifest.yaml`（或 Element Web manager 房间粘贴 `at/create_agents_messages.md` 替换 `<MOCK_TOOL_BASE_URL>` 后的版本）。
4. Worker 包在 `worker_packages/*.zip`（7 个已生成），需 `agentteams import` 进集群。
5. 进 Team 房间，事故任务以 `@antinet-leader`（TeamLeader Worker）开头派发。

> 注意：路径 B 的 7 个 Worker 包此前从未 `agentteams apply/import` 进活体集群；copaw 真入口是
> `copaw-worker-entrypoint.sh`，包内 `run_worker.py`+`manifest.json(kind:WorkerPackage)` 为自建约定，需 live import 验证。
