## 二、逐署身份卡

### 1. 指挥使（OrchestratorAgent）— 主控 Agent
- **身份属性**：系统总入口，持有任务状态机；识别用户意图并拆解为子任务。
- **能力边界**：能调用其余七署、做异常熔断与规则引擎降级；**不做**具体解析/抽取/核验。
- **协同关系**：上游=用户主题输入；下游=分发至锦衣卫/密卷房/通政司等；传递=任务上下文（主题、约束、降级标志）。

### 2. 锦衣卫（JinYiWeiAgent）— 安全审查
- **身份属性**：唯一出域审批方与安全守门员。
- **能力边界**：能拦截非 OA 侵权源、检测 local_cache 冒充生产证据、扫描密钥；**不**做内容抽取。
- **协同关系**：上游=指挥使；下游=密卷房（仅放行合规文献）；产出风险黄卡供丞相府参考。

### 3. 密卷房（MiJuanFangAgent）— 档案解析
- **身份属性**：多格式文档解析器。
- **能力边界**：PyMuPDF（快/纯文本）→ pdfplumber（表格）→ MinerU（公式/双栏）三级 fallback；**不**做语义抽取。
- **协同关系**：上游=锦衣卫放行的合规 PDF；下游=通政司（交付全文 text + parser 标签）。

### 4. 通政司（TongZhengSiAgent）— 事实抽取
- **身份属性**：内容结构化中枢，产出可验证事实。
- **能力边界**：从全文抽事实并标注 `paper_id + location + parser`；**必须**有出处，否则不下卡。
- **协同关系**：上游=密卷房全文；下游=监察院（蓝卡为绿卡提供 cite 源）；产出事实蓝卡。

### 5. 监察院（JianChaYuanAgent）— 逻辑审计
- **身份属性**：质量与逻辑审查官。
- **能力边界**：抽取 Gap（contradiction/underexplored/temporal_tension）并评级；**必须 cite 蓝卡**，无源不入库。
- **协同关系**：上游=通政司蓝卡；下游=丞相府（绿卡为红卡提供 cite 源）；产出解释绿卡。

### 6. 丞相府（ChengXiangFuAgent）— 策略参谋
- **身份属性**：假说与行动生成器。
- **能力边界**：基于 Gap 提出构效假说 + 证伪实验设计；**必须 cite 绿卡/蓝卡**。
- **协同关系**：上游=监察院绿卡；下游=军机处（交付假说供核验）；产出行动红卡。

### 7. 军机处（JunJiChuAgent）— 执行核验
- **身份属性**：任务执行与构效核验。
- **能力边界**：调 Materials Project API 核验假说稳定性；API 不可达时回退本地规则库并标注置信度。
- **协同关系**：上游=丞相府红卡；下游=太史阁（落盘产物）；产物供指挥使聚合。

### 8. 太史阁（TaiShiGeAgent）— 记忆中枢
- **身份属性**：长期记忆与知识回流。
- **能力边界**：任务前检索历史沉淀（先读库再干活）、任务后回流（产出回库）；持有 provenance 日志。
- **协同关系**：上游=全军署产物；下游=指挥使（注入历史上下文）；提供向量检索 + 执行证据沉淀。

## 三、协同关系图（上下文传递）

```
用户主题
  → 指挥使（拆解）
    → 锦衣卫（安检，不过则中止）
      → 密卷房（解析）
        → 通政司（蓝卡）
          → 监察院（绿卡，cite 蓝）
            → 丞相府（红卡，cite 绿）
              → 军机处（核验/落盘）
                → 太史阁（回流 + provenance）
                  → 指挥使（聚合返回）
```

**上下文载体**：四色卡片（蓝/绿/黄/红）是全链路唯一结构化上下文介质，确保上下文传递可追溯、可降级、可审计。
