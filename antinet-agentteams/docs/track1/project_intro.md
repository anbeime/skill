# 作品简介（GOAI 赛道一 · Agent Infra 新智基座）

> 初赛必交材料，500 字以内。用于官网作品提交。

---

**作品名称**：Antinet·八官署——面向复杂知识任务的多智能体基础设施

**问题与场景**
企业/科研中存在大量"信息过载、结论难溯源、知识难沉淀"的复杂任务。以材料文献调研为例，需在海量论文识别矛盾/空白/时间张力并产出可证伪假说；传统单 Agent 把检索/解析/抽取/核验搅在一起，难以审计与降级。

**解决方案**
以"明朝内阁"治理体系映射为多智能体框架：指挥使编排、锦衣卫合规防假、密卷房解析、通政司事实蓝卡、监察院解释绿卡、丞相府行动红卡、军机处核验、太史阁记忆与 provenance。八署职责隔离，四色卡片结构化传递上下文，全链路留痕。

**创新点**
①四色卡片可溯源审计；②以 AgentTeams 为协同基点；③15 个热插拔 Skill；④太史阁记忆+共享状态+可观测；⑤熔断降级不崩盘。

**价值与进展**
Apache 2.0 开源，verify PASS；八署串连通跑（蓝8绿7红4/解析7/10），接入本地NPU，AgentTeams/Agent Identity/Skill 齐备。
