## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/anbeime/skill.git
cd skill
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run an update

```bash
# Run a one-shot update
python main.py --once

# Start the scheduled update daemon
python main.py --daemon

# Show data statistics
python main.py --stats

# Export to CSV
python main.py --export skills.csv

# Verbose logging
python main.py --once -v
```

### 4. Browse the skills

Visit the [online Skill Store](https://skill.vercel.app) or browse local files:

```bash
# View the official skill list
cat data/skills.json

# View the local skill list
cat data/local_skills.json

# View the skill documents
ls docs/
```

## 🛠️ Skill Validator

A built-in validator is included for checking whether `SKILL.md` complies with the spec:

```bash
# Validate all skills
python tools/skill_validator.py validate

# Validate a single skill
python tools/skill_validator.py validate skills/agent-team

# Read skill properties
python tools/skill_validator.py read-properties skills/agent-team --json

# Generate an XML prompt (for AI invocation)
python tools/skill_validator.py to-prompt skills/agent-team
```

See the [tool documentation](tools/README.md).
